> 每个阶段配套一个实战项目，项目之间逐步积累，最终整合成个人量化平台 `mini-quant`

### 项目依赖关系

```
P1 数据仓库 ──┬──► P2 仪表板 ──► P3 统计报告
              │
              └──► P4 回测引擎 ──┬──► P5 CTA ──► P6 配对交易
                                 │
                                 └──► P7 多因子 ──► P8 组合优化 ──► P9 ML 选股 ──► P10 LLM 助手
                                                                        │
              P11 做市模拟器 ──► P13 实盘系统 ◄─────────────────────────┘
              P12 期权工具 ───────────┘
                                      │
                                      ▼
                              P14 mini-quant 平台
```

### 通用要求

- 每个项目包含 `README.md`、`requirements.txt`、`tests/`
- 核心逻辑必须有测试，测试使用合成数据，不依赖网络
- 研究类项目必须输出报告：样本区间、成本假设、基准对比、样本外结果
- 优先复用前面项目的代码（如 P1 的 `Warehouse`、P4 的回测引擎）

## Phase 1: 本地行情数据仓库

> **目录**: [`projects/phase-01-market-data-pipeline/`](phase-01-market-data-pipeline/)

### 项目描述

增量下载 A 股不复权日线与等比复权因子，按年分区存为 Parquet，用 DuckDB 查询，并生成数据质量报告。这是后续所有项目的数据基础。

### 功能需求

- [x] `init` / `update` / `query` / `report` 四个子命令
- [x] 东方财富 + 新浪双数据源，重试与限速
- [x] 主键 upsert，增量更新幂等
- [x] 等比后复权价格计算
- [x] 7 类数据质量检查与 Markdown 报告
- [x] 离线合成数据模式与 pytest 测试

## Phase 2: 股票分析仪表板

> **目录**: `projects/phase-02-stock-dashboard/`

### 项目描述

输入股票代码，输出一份完整的分析报告：收益、波动、回撤统计，技术指标图，以及与沪深 300 的对比。

### 功能需求

- [ ] 从 P1 数据仓库读取数据（缺失时自动下载）
- [ ] 收益统计：年化收益、年化波动、最大回撤及起止日期、分年度收益
- [ ] 技术指标：MA、MACD、RSI、布林带、ATR
- [ ] 相对表现：超额收益、Beta、滚动相关性
- [ ] 输出 HTML 报告（Plotly 交互图）

### 技术要点

- 向量化计算技术指标
- 重采样与多频率统计
- 回撤区间识别

---

## Phase 3: 风险收益统计报告生成器

> **目录**: `projects/phase-03-stats-report/`

### 项目描述

对任意资产或策略收益序列生成统计诊断报告，回答"这个收益分布有什么特点、风险有多大、收益是否显著"。

### 功能需求

- [ ] 分布诊断：偏度、峰度、Jarque-Bera 检验、Q-Q 图
- [ ] 尾部风险：历史 VaR / CVaR
- [ ] 时间序列：ADF 检验、自相关、Ljung-Box 检验
- [ ] GARCH(1,1) 波动率拟合与预测
- [ ] Bootstrap 置信区间与蒙特卡洛情景（最大回撤分布）
- [ ] Sharpe 显著性检验

### 技术要点

- statsmodels、arch
- Block Bootstrap 保留自相关结构

## Phase 4: 迷你回测引擎

> **目录**: `projects/phase-04-mini-backtester/`

### 项目描述

从零实现支持 A 股约束的事件驱动回测引擎，并与 backtrader 的结果对拍。

### 功能需求

- [ ] 事件循环：行情 → 策略 → 订单 → 撮合 → 持仓 / 资金更新
- [ ] A 股约束：T+1、涨跌停不可成交、停牌、整数手、ST 规则按日期生效
- [ ] 成本模型：佣金（最低 5 元）、印花税、过户费、滑点
- [ ] 绩效报告：净值、回撤、Sharpe、Sortino、换手、成本占比
- [ ] 与向量化回测、backtrader 结果一致性测试
- [ ] 未来函数检测：截断数据后信号是否改变

### 技术要点

- 订单与持仓的数据模型
- 不复权价格撮合、复权价格计算收益

## Phase 5: 期货 CTA 多品种组合

> **目录**: `projects/phase-05-cta-portfolio/`

### 项目描述

在 10 个以上国内期货品种上构建趋势跟踪组合，包含换月处理、波动率目标仓位和稳健性报告。

### 功能需求

- [ ] 单合约数据拼接与比例调整连续合约
- [ ] 至少 3 种趋势信号（均线、通道突破、时间序列动量）
- [ ] ATR / 波动率目标仓位，组合层面风险预算
- [ ] 参数平原分析与跨品种稳健性检验
- [ ] 成本敏感性分析

### 技术要点

- 换月、保证金、合约乘数
- 参数稳健性而非单点最优

## Phase 6: 配对交易系统

> **目录**: `projects/phase-06-pairs-trading/`

### 功能需求

- [ ] 候选对筛选：距离法 + 协整检验（处理多重检验）
- [ ] 半衰期估计与持仓周期设置
- [ ] 卡尔曼滤波对冲比
- [ ] Z-score 开平仓与止损规则
- [ ] 滚动协整检验，识别关系断裂

### 技术要点

- A 股做空受限的替代方案（ETF、股指期货）

- [ ] 去极值、标准化、行业市值中性化
- [ ] IC / ICIR / 分层回测 / 因子相关性
- [ ] 因子合成与组合回测（接入 P4 引擎）

## Phase 11: 加密订单簿做市模拟器

### 功能需求

- [ ] ccxt WebSocket 订单簿采集与本地存储

- [ ] 对称报价 vs AS 模型对比
- [ ] 库存风险、逆向选择（Markout）分析

> ⚠️ 仅使用公开行情数据做研究模拟，遵守所在地法律法规。
