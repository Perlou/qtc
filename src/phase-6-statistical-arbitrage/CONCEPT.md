## 1. 引言：什么是统计套利

### 1.1 定义

**套利（Arbitrage）** 在教科书中的定义是"零成本、零风险、正收益"。现实中几乎不存在这种机会，就算出现也会被最快的参与者在毫秒级消灭。

**统计套利（Statistical Arbitrage）** 是一种更务实的版本：同时持有多头和空头，构建一个**对市场方向不敏感**、其价值**在统计上倾向于回归某个均衡水平**的组合，在偏离时入场、回归时离场。它赚的是"**相对价格偏离的修复**"，而不是"市场整体涨跌"。

> 比喻：醉汉遛狗（Murray, 1994 用来解释协整的经典比喻）。醉汉（股票 A）走路歪歪扭扭，完全不可预测；他的狗（股票 B）也在乱跑。单看任何一个，都是随机游走。但狗被一根**绳子**拴着——它们之间的距离不会无限扩大。统计套利就是在"绳子被拉得很长"时押注它会收回来。
>
> 风险也在这个比喻里：**绳子可能会断**。

### 1.2 套利的谱系

| 类型 | 例子 | 收敛是否有保证 | 主要风险 |
| --- | --- | --- | --- |
| **纯套利** | 同一资产在两个市场的瞬时价差 | 有（同一物）| 执行速度、费用 |
| **期现 / 跨期套利** | 股指期货 vs 现货 ETF 篮子；近月 vs 远月 | 期现：到期收敛有制度保证；跨期：无 | 持有期间价差扩大、资金成本、交割规则 |
| **资金费率套利** | 现货多 + 永续空 | 无到期，靠资金费率持续为正 | 费率反转、交易所风险、强平 |
| **统计套利 / 配对交易** | 两只同行业股票的价差 | **无**，只有统计规律 | 协整断裂、拥挤、模型错误 |

从上到下，"收敛保证"越来越弱，可容纳的资金越来越大，对**风险管理**的要求越来越高。

## 2. 配对交易原理与选对

### 2.1 配对交易的基本逻辑（`01-pairs-trading-intro.py`）

1. 找到两个"本应走势相近"的资产 A、B（例如两家同行业银行、两只跟踪同一指数的 ETF）
2. 构造价差 $s_t = P^A_t - \beta P^B_t$
3. 价差偏高时：做空 A、做多 B（押注价差缩小）
4. 价差偏低时：做多 A、做空 B（押注价差扩大）
5. 价差回到均值时平仓

```
价差 s_t
   │
 +2σ ─────────────●──────────────────────●────────  ← 做空价差（空 A 多 B）
   │            ╱   ╲                  ╱  ╲
 均值 ────╲───╱───────╲──────╱╲──────╱──────╲─────  ← 平仓
   │       ╲ ╱          ╲   ╱  ╲   ╱
 -2σ ───────●────────────●──────●─────────────────  ← 做多价差（多 A 空 B）
   │
   └─────────────────────────────────────────────▶ 时间
```

**市场中性**：如果大盘整体下跌 5%，A 和 B 都会下跌，多头的亏损和空头的盈利大致抵消，组合只暴露于 A、B 之间的**相对**表现。

### 2.2 两种主流选对方法

#### 方法一：距离法（Distance Method）

Gatev、Goetzmann、Rouwenhorst（2006）的经典研究：

1. 把每只股票的价格**标准化**为累计收益指数（起点为 1）
2. 在**形成期**（12 个月）内计算每对股票标准化价格的**偏差平方和**（SSD）
3. 选 SSD 最小的若干对
4. 在随后的**交易期**（6 个月）内，偏离超过形成期历史标准差的 2 倍时开仓，价格再次交叉时平仓

$$
\text{SSD}_{AB} = \sum_{t=1}^{T} \left(\tilde{P}^A_t - \tilde{P}^B_t\right)^2
$$

- $\tilde{P}_t$：标准化后的价格（累计收益指数）

优点是简单、无模型假设；缺点是**相似 ≠ 会回归**，SSD 小只说明过去走得近。

#### 方法二：协整法（Cointegration Method）

用统计检验确认价差**平稳**（第 3 节详解）。优点是有理论依据，能给出对冲比 $\beta$；缺点是对样本区间敏感，检验结果不稳定。

### 2.3 选对的基本面过滤

统计检验之前，先用**经济逻辑**缩小范围：

| 维度 | 好的配对 | 差的配对 |
| --- | --- | --- |
| 行业 | 同一细分行业（如两家股份制银行）| 跨行业（统计上偶然相关）|
| 商业模式 | 收入来源、成本结构相似 | 一家主营 A 业务，另一家转型中 |
| 规模 / 流动性 | 都足够大、可交易 | 一只流动性很差 |
| 驱动因素 | 受相同宏观 / 商品价格驱动（如螺纹钢 vs 热卷）| 驱动因素不同 |
| 可做空 | 两条腿都能交易 | 空头腿无法借券 |

### 2.4 选对中的多重检验陷阱

在 100 只股票中两两组合，有 $\binom{100}{2} = 4950$ 对。如果用 5% 的显著性水平做协整检验，**即使所有配对都没有真正的协整关系**，也会有约 $4950 \times 5\% \approx 247$ 对"通过检验"。

```python
from math import comb
n_stocks = 100
n_pairs = comb(n_stocks, 2)
print(n_pairs, n_pairs * 0.05)   # 4950 对，约 247 个假阳性
```

**对策**：

1. 先用行业 / 基本面过滤，把候选对数从几千降到几十
2. 使用更严格的显著性水平，或 Bonferroni / FDR 校正
3. **最重要**：样本内选对，**样本外**检验。只看样本外表现

### 2.5 A 股配对交易的现实约束

- **做空受限**：A 股融券券源有限、成本较高，且近年来融券及转融券业务受到明显收紧（以监管最新规则为准）。纯 A 股个股的双边配对交易在实践中很难大规模执行。
- **可行替代**：
  - ETF 配对（部分 ETF 可融券，或用股指期货替代空头腿）
  - 期货品种间配对（螺纹 vs 热卷、豆油 vs 棕榈油、黄金 vs 白银），做空无障碍——本阶段的很多例子都以期货为主
  - 港股、美股等做空便利的市场
  - "多头 + 股指期货对冲"的变体（Phase 7 指数增强）

## 3. 平稳性与协整检验

### 3.1 相关 ≠ 协整（`02-cointegration-tests.py`）

这是本阶段最重要的概念区分（Phase 3 已有铺垫）。

| | 相关性（Correlation）| 协整（Cointegration）|
| --- | --- | --- |
| 衡量对象 | **收益率**的同向变动程度 | **价格水平**之间的长期均衡 |
| 时间尺度 | 短期 | 长期 |
| 交易含义 | 今天一起涨跌 | 走远了会回来 |
| 典型反例 | 两只股票日收益高度相关，但长期一只翻倍一只腰斩 → 高相关、不协整 | 两条序列日收益相关性一般，但价差始终围绕常数波动 → 低相关、协整 |

```
高相关、不协整                         协整（不一定高相关）
价格                                   价格
  │            ╱ A                       │    ╱╲  ╱╲ A
  │         ╱╱                           │  ╱╲╱  ╲╱  ╲╱╲
  │      ╱╱  ╱ B                         │  ╲╱╲  ╱╲  ╱╲╱ B
  │   ╱╱ ╱╱                              │    ╲╱  ╲╱
  │ ╱╱╱                                  │
  └──────────▶ 时间                       └──────────▶ 时间
  每天同涨同跌，但差距越来越大             各自乱走，但始终拴在一起
```

**配对交易需要的是协整**，不是相关。

### 3.2 平稳性与 ADF 检验回顾

**平稳（Stationary）** 序列的均值、方差不随时间变化，偏离后倾向于回到均值。价格通常**不平稳**（随机游走，Phase 3 中称为 I(1)，即一阶单整：差分一次才平稳）。

ADF（Augmented Dickey-Fuller）检验的回归形式：

$$
\Delta s_t = \alpha + \gamma\, s_{t-1} + \sum_{i=1}^{p} \phi_i \Delta s_{t-i} + \varepsilon_t
$$

- $\Delta s_t = s_t - s_{t-1}$：价差的一阶差分
- $\gamma$：关键系数。$\gamma < 0$ 表示"价差越高，下一期越倾向下降"，即均值回归
- 原假设 $H_0: \gamma = 0$（有单位根，不平稳）；p 值小于 0.05 则拒绝原假设，认为平稳
- 滞后项 $\Delta s_{t-i}$ 用来吸收序列自相关

**协整的定义**：若 $P^A$ 和 $P^B$ 都是 I(1)，但存在 $\beta$ 使得 $s_t = P^A_t - \beta P^B_t$ 是平稳的 I(0)，则称 A、B 协整，$\beta$ 是协整系数（对冲比）。

### 3.3 Engle-Granger 两步法

**第一步**：OLS 回归估计对冲比

$$
P^A_t = \alpha + \beta P^B_t + u_t
$$

**第二步**：对残差 $\hat{u}_t = P^A_t - \hat{\alpha} - \hat{\beta} P^B_t$ 做 ADF 检验。

```python
import numpy as np
import pandas as pd
import statsmodels.api as sm
from statsmodels.tsa.stattools import adfuller, coint

def engle_granger(y: pd.Series, x: pd.Series):
    """y、x 为价格序列（或对数价格）。返回对冲比、价差、协整检验 p 值"""
    ols = sm.OLS(y, sm.add_constant(x)).fit()
    alpha, beta = ols.params
    spread = y - beta * x - alpha
    t_stat, p_value, crit = coint(y, x)     # 使用 MacKinnon 协整临界值
    return beta, spread, p_value

beta, spread, p = engle_granger(df["A"], df["B"])
print(f"beta={beta:.3f}, 协整 p 值={p:.4f}")
```

> ⚠️ **关键细节：不能直接用 `adfuller(spread)` 的 p 值判断协整**。OLS 已经选择了"让残差尽可能小"的 $\beta$，残差天然看起来比真实情况更平稳。Engle-Granger 检验需要使用更严格的协整临界值（MacKinnon 临界值）。`statsmodels` 的 `coint()` 已经处理了这一点。

**Engle-Granger 的局限**：

| 局限 | 说明 |
| --- | --- |
| **方向依赖** | A 对 B 回归和 B 对 A 回归，得到的 $\beta$ 不是互为倒数，检验结论也可能不同。实践中两个方向都检验 |
| **只能处理一个协整关系** | 三个及以上资产时可能存在多个协整向量 |
| **对样本敏感** | 换一个起止日期，p 值可能从 0.01 变成 0.3 |
| **价格 vs 对数价格** | 价格回归得到"股数比"；对数价格回归得到"金额比"的近似。两者结论可能不同，要与交易方式一致 |

### 3.4 Johansen 检验

Johansen 检验基于向量误差修正模型（VECM），可以同时检验**多个**资产之间存在**几个**协整关系，并且不依赖于谁是因变量。

VECM 形式：

$$
\Delta \mathbf{P}_t = \Pi \mathbf{P}_{t-1} + \sum_{i=1}^{k} \Gamma_i \Delta \mathbf{P}_{t-i} + \boldsymbol{\varepsilon}_t
$$

- $\mathbf{P}_t$：$n$ 个资产的价格向量
- $\Pi$：长期影响矩阵，它的**秩** $r$ 就是协整关系的个数
- $r = 0$：无协整；$0 < r < n$：有 $r$ 个协整向量；$r = n$：所有序列本身就平稳

Johansen 提供两种统计量：

- **迹统计量（Trace）**：$H_0$：协整秩 $\le r$
- **最大特征值统计量（Max-Eigen）**：$H_0$：协整秩 $= r$，备择 $= r+1$

从 $r=0$ 开始依次检验，第一个**不能拒绝**的 $r$ 就是协整秩。

```python
from statsmodels.tsa.vector_ar.vecm import coint_johansen

prices = df[["A", "B", "C"]].dropna()
res = coint_johansen(prices, det_order=0, k_ar_diff=1)   # det_order=0：含常数项

print("r   迹统计量   95%临界值")
for r in range(prices.shape[1]):
    print(r, round(res.lr1[r], 2), round(res.cvt[r, 1], 2))   # cvt 列：90%、95%、99%

w = res.evec[:, 0]                  # 第一个（最强）协整向量
basket = prices.values @ w          # 平稳组合：w1*A + w2*B + w3*C
```

**实际意义**：Johansen 适合构建**三个以上资产的平稳组合**（例如一篮子同行业股票、黑色系"螺纹 + 铁矿 + 焦炭"的利润价差）。但资产越多，交易成本越高，过拟合风险越大。

## 4. Z-score 信号与半衰期

### 4.1 OU 过程：均值回归的数学模型（`03-zscore-signals.py`）

平稳价差最常用的连续时间模型是 **Ornstein-Uhlenbeck（OU）过程**：

$$
ds_t = \theta(\mu - s_t)\,dt + \sigma\, dW_t
$$

- $s_t$：价差
- $\mu$：长期均值，价差"想回去"的地方
- $\theta > 0$：**回归速度**。偏离 $\mu$ 越远，拉回的力越大（$\theta(\mu - s_t)$ 这一项就是"弹簧的回复力"）
- $\sigma$：噪声强度；$dW_t$：布朗运动增量（随机扰动）

> 比喻：一个挂在弹簧上、同时被风吹的小球。$\theta$ 是弹簧硬度，$\sigma$ 是风力。弹簧越硬，偏离后回来得越快。

### 4.2 半衰期（Half-Life）

**半衰期**：偏离均值后，期望偏离**缩小一半**所需的时间。

对 OU 过程，期望偏离按指数衰减：$E[s_t - \mu] = (s_0 - \mu)e^{-\theta t}$。令其等于一半：

$$
e^{-\theta h} = \frac{1}{2} \implies h = \frac{\ln 2}{\theta}
$$

**离散估计**：用日频数据做回归

$$
\Delta s_t = a + b\, s_{t-1} + \varepsilon_t
$$

它等价于 AR(1)：$s_t - \mu = (1+b)(s_{t-1} - \mu) + \varepsilon_t$。偏离每期乘以 $(1+b)$，令 $(1+b)^h = 1/2$：

$$
h = -\frac{\ln 2}{\ln(1+b)} \approx -\frac{\ln 2}{b} \quad (\text{当 } |b| \text{ 较小时})
$$

- $b < 0$ 才有均值回归；$b \ge 0$ 时半衰期无意义（不回归）

```python
def half_life(spread: pd.Series) -> float:
    s = spread.dropna()
    lag = s.shift(1)
    delta = s - lag
    data = pd.concat([delta, lag], axis=1, keys=["d", "lag"]).dropna()
    b = sm.OLS(data["d"], sm.add_constant(data["lag"])).fit().params["lag"]
    if b >= 0:
        return np.inf                       # 不均值回归
    return -np.log(2) / np.log(1 + b)

hl = half_life(spread)
print(f"半衰期约 {hl:.1f} 个交易日")
```

### 4.3 半衰期的实际用途

| 用途 | 做法 |
| --- | --- |
| **筛选配对** | 半衰期太长（如 > 60 个交易日）：资金占用久，期间不确定性大；太短（如 < 1 天）：可能是噪声或买卖价差反弹（bid-ask bounce），扣成本后无利可图 |
| **设定 Z-score 窗口** | 均值 / 标准差的滚动窗口取半衰期的若干倍（例如 1–3 倍），使窗口与回归节奏匹配 |
| **时间止损** | 持仓超过半衰期的 2–3 倍仍未回归，说明关系可能改变，强制平仓 |
| **监控关系变化** | 滚动计算半衰期，若明显变长，是协整减弱的预警 |

### 4.4 Z-score 交易规则

$$
z_t = \frac{s_t - \bar{s}_t(L)}{\sigma_{s,t}(L)}
$$

- $\bar{s}_t(L)$、$\sigma_{s,t}(L)$：过去 $L$ 天价差的滚动均值与标准差

| 条件 | 动作 |
| --- | --- |
| $z_t > +2$ | 做空价差：空 1 份 A，多 $\beta$ 份 B |
| $z_t < -2$ | 做多价差：多 1 份 A，空 $\beta$ 份 B |
| $\lvert z_t \rvert < 0.5$ | 平仓 |
| $\lvert z_t \rvert > 4$ | 止损（关系可能已破裂）|
| 持仓 > 3 × 半衰期 | 时间止损 |

```python
def pair_backtest(y, x, beta, lookback, entry=2.0, exit=0.5, stop=4.0):
    """固定对冲比的配对交易。pos=+1 表示多 1 份 y、空 beta 份 x"""
    spread = y - beta * x
    z = (spread - spread.rolling(lookback).mean()) / spread.rolling(lookback).std()

    pos, cur = [], 0
    for zi in z:
        if np.isnan(zi):
            pos.append(0); continue
        if cur == 0:
            if zi > entry: cur = -1
            elif zi < -entry: cur = 1
        elif abs(zi) < exit or abs(zi) > stop:
            cur = 0      # 简化：止损后下一天可能立即重新入场，实盘应加冷却期

        pos.append(cur)
    pos = pd.Series(pos, index=y.index).shift(1).fillna(0)   # 次日执行

    pnl = pos * (y.diff() - beta * x.diff())                  # 每份价差的盈亏（价格单位）
    gross = (y.abs() + beta * x.abs()).shift(1)               # 两条腿的总名义金额
    ret = (pnl / gross).fillna(0)                             # 近似收益率（未扣成本）
    return z, pos, ret
```

> ⚠️ 这里 $\beta$ 用全样本估计就是**前视偏差**。正确做法：在形成期估计 $\beta$、半衰期和 lookback，在交易期使用；或使用滚动 / 卡尔曼滤波估计（第 5 节）。

### 4.5 头寸配比：美元中性 vs Beta 中性

| 方式 | 配比 | 中性于 | 说明 |
| --- | --- | --- | --- |
| **协整比例** | 1 股 A 对 $\beta$ 股 B | 价差本身 | 价格回归得到的 $\beta$ 直接就是股数比 |
| **美元中性** | 多空金额相等 | 资金 | 简单，但不一定让价差平稳 |
| **Beta 中性** | 多空的市场 Beta 敞口相等 | 大盘涨跌 | 需要另行估计每只股票相对大盘的 Beta |

实践中，配对交易的盈亏应当用**与检验一致的配比**计算，否则"检验过的平稳价差"和"实际交易的组合"不是同一个东西。

## 5. 卡尔曼滤波动态对冲比

### 5.1 为什么需要动态对冲比（`04-kalman-filter-hedge.py`）

两只股票之间的关系会**缓慢漂移**：公司规模变化、业务结构变化、资本结构变化……一个 3 年前估计的 $\beta$ 今天可能已不再合适。

常见做法对比：

| 方法 | 优点 | 缺点 |
| --- | --- | --- |
| 全样本 OLS | 简单 | 前视偏差，无法适应变化 |
| 滚动 OLS | 能适应变化 | 窗口长度是额外参数；窗口边缘数据"突然进出"导致 $\beta$ 跳动 |
| **卡尔曼滤波** | 每个新数据点平滑更新 $\beta$；自带不确定性估计 | 需要设定噪声参数；理解门槛稍高 |

### 5.2 直觉：GPS 导航

> 比喻：卡尔曼滤波就像汽车导航。车的位置（真实 $\beta$）看不见，只能通过 GPS 信号（每天的价格）间接观测，而 GPS 信号有噪声。导航系统每一刻都做两件事：
> 1. **预测**：根据之前的位置推测现在在哪（"$\beta$ 应该和昨天差不多"），同时承认"我的不确定性变大了一点"
> 2. **更新**：收到新的 GPS 信号后，按"我有多信任预测 vs 多信任新信号"的比例修正位置
>
> 这个"信任比例"就是**卡尔曼增益**：预测越不确定、观测越精确，就越相信新观测。

### 5.3 状态空间模型

**状态方程**（隐藏状态怎么演化）：对冲比和截距做随机游走

$$
\boldsymbol{\beta}_t = \boldsymbol{\beta}_{t-1} + \boldsymbol{\omega}_t, \quad \boldsymbol{\omega}_t \sim N(0, V_w)
$$

- $\boldsymbol{\beta}_t = [\beta_t, \alpha_t]^T$：第 $t$ 天的斜率（对冲比）和截距
- $V_w$：状态噪声协方差，控制 $\beta$ 每天"允许漂移多少"

**观测方程**（看得见的数据怎么产生）：

$$
y_t = H_t \boldsymbol{\beta}_t + \varepsilon_t, \quad H_t = [x_t, 1], \quad \varepsilon_t \sim N(0, V_e)
$$

- $y_t, x_t$：两个资产的价格
- $V_e$：观测噪声方差

**递推步骤**：

$$
\begin{aligned}
&\text{预测：} && \hat{\boldsymbol{\beta}}_{t|t-1} = \hat{\boldsymbol{\beta}}_{t-1}, \quad R_t = P_{t-1} + V_w \\
&\text{预测误差：} && e_t = y_t - H_t \hat{\boldsymbol{\beta}}_{t|t-1}, \quad Q_t = H_t R_t H_t^T + V_e \\
&\text{卡尔曼增益：} && K_t = R_t H_t^T / Q_t \\
&\text{更新：} && \hat{\boldsymbol{\beta}}_t = \hat{\boldsymbol{\beta}}_{t|t-1} + K_t e_t, \quad P_t = R_t - K_t H_t R_t
\end{aligned}
$$

- $P_t$：状态估计的协方差（"我对 $\beta$ 有多不确定"）
- $R_t$：预测后的状态协方差
- $e_t$：**预测误差**——用昨天的 $\beta$ 预测今天的 $y$，差了多少。**这就是价差偏离**
- $Q_t$：预测误差的方差，$\sqrt{Q_t}$ 就是价差偏离的"标准差"

### 5.4 代码实现

```python
def kalman_hedge(y: np.ndarray, x: np.ndarray, delta: float = 1e-4, ve: float = 1e-3):
    """动态估计 y = beta*x + alpha。
    delta 控制 beta 漂移速度（越大越灵活、越不稳定）；ve 为观测噪声方差。
    返回：states[t] = [beta_t, alpha_t]，预测误差 e，预测误差方差 Q"""
    n = len(y)
    Vw = delta / (1 - delta) * np.eye(2)    # 状态噪声协方差
    b = np.zeros(2)                         # 初始状态 [beta, alpha]
    P = np.zeros((2, 2))                    # 初始状态协方差
    states = np.zeros((n, 2))
    e = np.zeros(n)
    Q = np.zeros(n)

    for t in range(n):
        H = np.array([x[t], 1.0])
        R = P + Vw                          # 预测：不确定性扩散
        e[t] = y[t] - H @ b                 # 用旧状态预测，计算误差
        Q[t] = H @ R @ H + ve
        K = R @ H / Q[t]                    # 卡尔曼增益
        b = b + K * e[t]                    # 更新状态
        P = R - np.outer(K, H) @ R
        states[t] = b
    return states, e, Q

states, e, Q = kalman_hedge(df["A"].values, df["B"].values)
beta_t = pd.Series(states[:, 0], index=df.index)
z_kf = pd.Series(e / np.sqrt(Q), index=df.index)    # 天然的 Z-score
```

**交易规则**（Ernest Chan《Algorithmic Trading》中的经典示例做法）：

- $e_t < -\sqrt{Q_t}$：价差偏低，做多价差（多 A，空 $\beta_t$ 份 B）
- $e_t > +\sqrt{Q_t}$：价差偏高，做空价差
- $e_t$ 回到 0 附近：平仓

### 5.5 实际意义与陷阱

| 要点 | 说明 |
| --- | --- |
| **无前视** | $e_t$ 只用了 $t-1$ 及之前的状态；$t$ 时刻的更新状态 $\hat{\boldsymbol{\beta}}_t$ 在 $t$ 日收盘后可得，用于 $t$ 日收盘或之后建仓 |
| **预热期** | 初始状态设为 0，前几十个观测的 $\beta$ 很不准，要丢弃 |
| **delta 的含义** | `delta` 太大：$\beta$ 跟着噪声乱跳，价差永远"平稳"（因为 $\beta$ 把偏离都吸收了），但没有交易价值；太小：退化为几乎不变的 OLS |
| **调参要样本外** | `delta`、`ve` 也是参数，同样要做参数平原和样本外检验；也可以用最大似然估计（如 `pykalman` 的 EM 算法）|
| **β 变化带来换手** | 每天 $\beta$ 变化都要调整 B 腿的数量，产生额外交易成本，回测中要计入 |
| **价格尺度** | 两个资产价格量级差异很大时，可先取对数或标准化，避免数值问题 |

> 💡 **卡尔曼滤波不是"让不协整的配对变协整"的魔法**。它适应的是**缓慢**漂移。如果两家公司的基本面突然分化（并购、重组、财务造假），卡尔曼滤波会"跟着走"，把结构性断裂误认为新的均衡——这正是第 9 节的协整断裂风险。

## 6. 期货跨期套利

### 6.1 跨期价差（`05-calendar-spread.py`）

**跨期套利（Calendar Spread）**：同一品种、不同到期月份的两个合约之间的价差交易。例如螺纹钢 01 合约和 05 合约。

$$
\text{Spread}_t = F_t(T_1) - F_t(T_2), \quad T_1 < T_2
$$

- $F_t(T)$：$t$ 时刻到期日为 $T$ 的期货价格

和配对交易相比，跨期套利的两条腿是**同一种商品**，联系更紧密；但价差同样**没有到期必然收敛的保证**——两个合约到期日不同。

### 6.2 持有成本模型：价差的"锚"

一个合约的"合理价格"可以用**持有成本（Cost of Carry）** 理解：今天买现货存到 $T$ 时刻交割，和今天买 $T$ 时刻的期货，应当等价。

$$
F_t(T) = S_t \cdot e^{(r + u - y)(T - t)}
$$

- $S_t$：现货价格
- $r$：资金成本（无风险利率）
- $u$：仓储成本（年化，按价格比例）
- $y$：便利收益（Convenience Yield）——持有现货带来的好处，例如库存紧张时可以随时用于生产
- $T - t$：剩余期限（年）

因此远近月理论价差约为：

$$
F(T_2) - F(T_1) \approx F(T_1)\,\left[e^{(r + u - y)(T_2 - T_1)} - 1\right]
$$

**直觉**：

- 库存充裕、需求疲软 → 便利收益低 → 远月高于近月（**Contango**），价差主要由资金 + 仓储成本决定，有一个"上限"（超过上限就可以买近月、接货、存起来、卖远月交割）
- 库存紧张 → 便利收益高 → 近月高于远月（**Backwardation**），价差理论上没有明确的上限

### 6.3 跨期套利的方向

| 策略 | 操作 | 押注 | 常见逻辑 |
| --- | --- | --- | --- |
| **牛市套利**（常称"正套"，买近卖远）| 买近月、卖远月 | 近月相对走强 | 现货紧张、去库存 |
| **熊市套利**（常称"反套"，卖近买远）| 卖近月、买远月 | 近月相对走弱 | 现货过剩、累库存 |

> ⚠️ 国内市场中"正套 / 反套"在跨期和期现语境中的含义不完全一致，交流时务必明确具体是哪条腿买、哪条腿卖。

### 6.4 统计视角的跨期价差交易

```python
def calendar_spread_signal(near: pd.Series, far: pd.Series, lookback=60, entry=2.0):
    """near/far：近月、远月合约收盘价（需用同一对合约，到换月时整体切换到下一对）"""
    spread = near - far
    z = (spread - spread.rolling(lookback).mean()) / spread.rolling(lookback).std()
    signal = pd.Series(0, index=spread.index)
    signal[z > entry] = -1     # 价差偏高：卖近买远
    signal[z < -entry] = 1     # 价差偏低：买近卖远
    return spread, z, signal.shift(1).fillna(0)
```

### 6.5 跨期套利的特有风险

| 风险 | 说明 |
| --- | --- |
| **临近交割** | 近月进入交割月后流动性骤降、保证金提高；多数商品期货品种不允许自然人客户持仓进入交割月（以交易所规则为准），必须提前平仓或移仓 |
| **逼仓（Squeeze）** | 近月可交割货源紧张时，空头可能面临近月价格大幅上涨，价差严重偏离"理论值" |
| **仓单与交割规则** | 交割品级、交割库、仓单有效期等制度细节会影响价差的合理区间 |
| **单边风险敞口** | 两条腿手数相同但价格不同，名义金额有差异；剧烈行情中两腿可能一条涨停、一条未涨停，无法同时成交 |
| **合约对切换** | 01-05 价差交易到期后，要切换到 05-09 或下一个 01-05，历史价差序列需要按合约对分段研究 |
| **交易所套利指令** | 部分交易所提供跨期套利指令和套利保证金优惠，可降低成本与腿风险，具体以交易所规则为准 |

## 7. 期现套利与基差

### 7.1 基差（`06-basis-arbitrage.py`）

**基差（Basis）** 是现货价格与期货价格之差。国内商品期货市场的常用定义：

$$
\text{Basis}_t = S_t - F_t
$$

- 基差为正：现货高于期货（期货**贴水**）
- 基差为负：现货低于期货（期货**升水**）

> 注意：海外文献中有时定义为 $F - S$，股指期货交易员也常直接说"期货相对指数升 / 贴水多少点"。读数据和研报时先确认符号约定。

**基差收敛**：到期交割时，期货价格必须收敛到现货价格（否则存在无风险套利），所以 $\text{Basis}_T \to 0$。这是期现套利唯一的"制度保证"。

```
价格
  │  F_t（期货，升水）
  │  ●─────●─────●────●───●──●─●
  │                              ●  ← 到期日收敛
  │  ●─────●─────●────●───●──●─●
  │  S_t（现货）
  └──────────────────────────────▶ 时间
                              到期日 T
```

### 7.2 股指期货的理论价格与无套利区间

股指期货的持有成本模型（现金交割，不涉及仓储，持有现货能拿到分红）：

$$
F^*_t = S_t \cdot e^{(r - q)(T - t)}
$$

- $S_t$：指数点位
- $r$：资金成本（年化）
- $q$：指数在剩余期限内的**分红率**（年化）
- $T - t$：剩余期限（年）

考虑交易成本后，存在一个**无套利区间**：

$$
\left[\,F^*_t - C,\ \ F^*_t + C\,\right]
$$

- $C$：完成一次套利（买卖现货篮子、开平期货、冲击成本、跟踪误差、资金成本）的总成本，折算为指数点

| 情形 | 操作 | 名称 |
| --- | --- | --- |
| $F_t > F^*_t + C$ | 买现货（ETF / 股票篮子）+ 卖期货，持有到期 | **正向期现套利** |
| $F_t < F^*_t - C$ | 卖现货 + 买期货 | **反向期现套利** |

```python
def index_futures_arb(S, F, r, q, days_to_expiry, cost_points):
    """S: 指数点位, F: 期货价格, r/q: 年化资金成本与分红率, cost_points: 总成本（点）"""
    T = days_to_expiry / 365
    fair = S * np.exp((r - q) * T)
    upper, lower = fair + cost_points, fair - cost_points
    if F > upper:
        action = "正向套利：买现货、卖期货"
    elif F < lower:
        action = "反向套利：卖现货、买期货"
    else:
        action = "无套利机会"
    annual_basis = (F - S) / S * 365 / days_to_expiry    # 年化升贴水率
    return fair, (lower, upper), annual_basis, action

print(index_futures_arb(S=3800, F=3780, r=0.02, q=0.02, days_to_expiry=30, cost_points=8))
```

### 7.3 A 股股指期货期现套利的现实

1. **反向套利难**：卖空现货需要融券，A 股融券受限。实践中，反向套利主要由**已持有现货的机构**完成：卖出手中的现货、买入贴水的期货替代，到期再换回（"期货替代现货"）。
2. **长期贴水**：历史上 IC、IM 等合约多数时间处于贴水状态，部分原因是大量市场中性 / 指数增强产品持续卖空期货对冲，以及反向套利难以执行。这对**用期货对冲的多头**是成本，对**用期货替代现货的多头**是收益。
3. **分红季节性**：A 股分红集中在年中（除权除息多在 5–8 月），这段时间到期的 IH、IF 合约理论价格需要扣减分红，表现为季节性的"深贴水"。**不考虑分红会错误判断贴水是"便宜"**。
4. **现货复制**：用 ETF 或股票篮子复制指数存在**跟踪误差**；成分股停牌、涨跌停会让篮子无法按计划建仓或平仓。
5. **期限结构**：同时挂牌的当月、下月、两个季月合约，年化基差往往不同，可以在其间选择对冲成本最低的合约。

### 7.4 商品期现套利

商品期现套利需要实物操作：买现货 → 运到交割库 → 注册仓单 → 期货交割。成本包括运费、仓储、质检、资金占用、增值税等，**对品级、地域、物流有极强依赖**，主要由现货贸易商完成。对于纯量化研究者，更常见的是把**基差作为信号**：

- 基差（现货 − 期货）走高、期货深度贴水 → 期货有向现货收敛的动力，常被作为 CTA 中 Carry / 基差动量类因子的输入
- 基差的季节性（如农产品的收获季节）

## 8. 加密永续合约资金费率套利

### 8.1 永续合约与资金费率（`07-crypto-funding-rate-arb.py`）

**永续合约（Perpetual Swap）** 是加密市场最主流的衍生品：像期货一样可以加杠杆、双向交易，但**没有到期日**。

问题：没有到期日，就没有"交割收敛"把合约价格拉回现货。永续合约用**资金费率（Funding Rate）** 机制解决这个问题：

```
永续价格 > 现货价格（市场偏多，合约溢价）
   → 资金费率为正 → 多头定期向空头支付费用
   → 做多变贵、做空有补贴 → 永续价格被压回现货附近

永续价格 < 现货价格（市场偏空，合约折价）
   → 资金费率为负 → 空头向多头支付
```

> 比喻：资金费率是一根"橡皮筋税"。合约价格偏离现货越远，偏离方向上那一边的人交的税就越多，直到没人愿意继续推高 / 压低价格。

### 8.2 资金费率的计算

以主流交易所的常见设计为例（具体参数、结算周期、上下限因交易所和合约而异，**以交易所最新规则为准**）：

$$
F = P + \text{clamp}(I - P,\ -0.05\%,\ +0.05\%)
$$

- $F$：每个结算周期的资金费率
- $P$：溢价指数（Premium Index），衡量永续价格相对现货指数价格的偏离
- $I$：利息率部分，常见设定为每 8 小时 0.01%
- $\text{clamp}(x, a, b)$：把 $x$ 限制在 $[a, b]$ 区间

**支付金额**：

$$
\text{资金费用} = \text{持仓名义价值} \times F
$$

结算周期常见为每 8 小时一次（每天 3 次），也有交易所或合约采用每 4 小时、每 1 小时结算。

**年化**：若每 8 小时费率稳定为 0.01%：

$$
0.01\% \times 3 \times 365 \approx 10.95\%
$$

牛市情绪高涨时，费率可能持续数倍于此。

### 8.3 Cash-and-Carry 策略结构

```
┌────────────────────────────────────────────────────────────────┐
│               资金费率套利（Delta 中性）                         │
├────────────────────────────────────────────────────────────────┤
│                                                                │
│   现货账户：买入 1 BTC                    Delta = +1            │
│   合约账户：做空 1 BTC 永续合约           Delta = -1            │
│   ──────────────────────────────────────────────               │
│   组合 Delta ≈ 0：BTC 涨跌对总价值影响很小                      │
│                                                                │
│   收益来源：资金费率为正时，空头每个周期收取资金费               │
│   成本：开平仓手续费（4 笔）、滑点、资金占用                     │
│                                                                │
│   费率转负时：空头要支付费用 → 考虑平仓或反向                    │
│   （反向需要借币卖空现货，成本和可行性另算）                     │
│                                                                │
└────────────────────────────────────────────────────────────────┘
```

```python
def funding_arb_stats(funding: pd.Series, periods_per_day: int = 3,
                      fee_per_leg: float = 0.0005, holding_days: float = 30):
    """funding: 每期资金费率序列（小数）。估算持有期净收益与年化"""
    gross_ann = funding.mean() * periods_per_day * 365
    pos_ratio = (funding > 0).mean()
    round_trip_cost = 4 * fee_per_leg                      # 现货买卖 + 合约开平
    expected = funding.mean() * periods_per_day * holding_days - round_trip_cost
    net_ann = expected / holding_days * 365
    return {"毛年化": gross_ann, "费率为正占比": pos_ratio,
            f"{holding_days}天净收益": expected, "净年化": net_ann}

# 关键结论：持有期越短，开平成本占比越大；
# 频繁根据费率正负来回切换，手续费会吃掉大部分收益
```

### 8.4 风险：远比看起来多

| 风险 | 说明 | 应对 |
| --- | --- | --- |
| **费率反转** | 市场情绪逆转后费率转负且持续，空头从收钱变付钱 | 监控滚动费率；设定退出阈值 |
| **空头腿强平** | 币价暴涨时，永续空头浮亏；若现货在另一个账户，盈利无法抵充保证金，空头可能被强制平仓，套利变成裸多 | 空头腿低杠杆；使用统一账户 / 组合保证金；预留充足保证金并自动划转 |
| **基差风险** | 开仓时永续溢价、平仓时溢价扩大或折价，会产生亏损 | 计入开平仓时的价差，避免在极端溢价时进场 |
| **自动减仓（ADL）** | 极端行情下，交易所可能强制减少盈利方的仓位，对冲被打破 | 了解交易所的 ADL 规则与排名机制 |
| **交易所 / 对手方风险** | 交易所倒闭、冻结提币、被盗（例如 2022 年 FTX 破产）| 分散交易所；控制单一交易所敞口；资金及时归集 |
| **稳定币风险** | 以 USDT / USDC 计价的保证金存在脱锚风险（例如 2023 年 3 月 USDC 曾短暂脱锚）| 分散计价资产；监控稳定币价格 |
| **拥挤** | 资金费率套利已被大量资金和产品化工具（例如以 Delta 中性永续空头为核心机制的合成美元类产品）规模化执行，费率中枢可能被压低 | 不要用历史高费率外推未来收益 |
| **合规风险** | 各司法辖区对加密资产交易的监管差异很大 | 遵守所在地法律法规 |

> 💡 **"无风险年化 X%"是营销话术**。资金费率套利是**承担尾部风险换取稳定小收益**的策略：平时像收房租，极端行情一次就可能抹掉数月甚至数年的收益。这正是本阶段学习检查"理解套利不等于无风险"的典型例子。

## 9. 统计套利的风险：协整断裂、拥挤与 Quant Quake

### 9.1 套利的极限（`08-stat-arb-risks.py`）

Shleifer & Vishny（1997）《The Limits of Arbitrage》指出：现实中的套利者用的是**别人的钱**、有**杠杆**、有**业绩考核**。当价差进一步扩大时，套利者不仅浮亏，还可能被投资人赎回、被追加保证金，被迫在**最差的时刻平仓**——这反过来又进一步推大价差。

一句常被归于凯恩斯的话：

> "市场保持非理性的时间，可能比你保持偿付能力的时间更长。"

### 9.2 协整断裂

**协整关系不是物理定律**，它由经济基本面维持，基本面一变就会断：

| 断裂原因 | 例子 |
| --- | --- |
| 公司层面事件 | 并购重组、主营业务转型、财务造假、重大诉讼 |
| 行业结构变化 | 新技术让同行业公司分化（如传统车企 vs 新能源车企）|
| 政策变化 | 行业监管、税收、补贴政策对两家公司影响不同 |
| 商品市场结构 | 产能、进出口政策、替代品变化改变两种商品之间的比价 |
| 指数 / 规则变化 | 成分股调整、交易规则变化 |

**检测：滚动协整检验**

```python
def rolling_coint_pvalue(y: pd.Series, x: pd.Series, window: int = 250, step: int = 20):
    """每 step 天，用过去 window 天数据做一次 Engle-Granger 检验"""
    out = {}
    for end in range(window, len(y), step):
        ys, xs = y.iloc[end - window:end], x.iloc[end - window:end]
        out[y.index[end - 1]] = coint(ys, xs)[1]
    return pd.Series(out)

pvals = rolling_coint_pvalue(df["A"], df["B"])
# p 值从长期 < 0.05 变为持续 > 0.2，或滚动半衰期显著变长，都是关系减弱的预警
```

> ⚠️ 滚动检验本身也有噪声：即使关系没变，p 值也会波动。不要单凭一次 p 值上升就判定断裂，要结合基本面、半衰期、价差偏离幅度综合判断。

### 9.3 拥挤（Crowding）

当很多资金运行相似的统计套利策略时：

1. **收益下降**：价差偏离一出现就被迅速交易，可获得的偏离变小。学术研究（如 Do & Faff, 2010）发现简单配对交易策略的收益随时间明显下降
2. **相关性上升**：大家持有相似的多空组合，彼此之间的收益高度相关
3. **踩踏风险**：一旦某个大玩家因为任何原因（甚至与这个策略无关的原因）被迫平仓，会推动价差向不利方向移动，触发其他人的止损和风控，形成连锁反应

### 9.4 2007 年 8 月 Quant Quake

```
┌────────────────────────────────────────────────────────────────┐
│               2007 年 8 月 "Quant Quake" 时间线                  │
├────────────────────────────────────────────────────────────────┤
│                                                                │
│  背景：次贷危机开始发酵，信用市场紧张                            │
│                                                                │
│  8 月第二周（约 8/6 – 8/9）                                     │
│   ├─ 许多量化股票多空（市场中性）基金同时出现罕见的巨大亏损     │
│   ├─ 大盘本身波动并不极端 —— 亏损来自"多空价差"的反向移动       │
│   └─ 多头持仓下跌、空头持仓上涨：典型的"去杠杆踩踏"              │
│                                                                │
│  8 月 10 日前后                                                 │
│   └─ 价差大幅反弹，坚持持有（且没被迫平仓）的基金收复部分损失    │
│                                                                │
│  事后解释（Khandani & Lo）                                      │
│   ├─ 很可能是一个或多个大型多策略基金因其他业务亏损而被迫        │
│   │  快速清算其股票多空组合                                     │
│   ├─ 由于大量基金持有相似的因子 / 统计套利头寸，抛售引发连锁     │
│   └─ 杠杆 + 拥挤 + 流动性 = 系统性风险                           │
│                                                                │
└────────────────────────────────────────────────────────────────┘
```

**教训**：

1. **"市场中性"不等于"无风险"**：你中性于大盘，但暴露于"同类策略集体平仓"这一隐藏因子
2. **策略的风险由持有者结构决定**：同样的头寸，没人持有时很安全，人人持有时很危险
3. **杠杆决定能否活下来**：价差最终修复了，但高杠杆的基金在修复之前就被迫止损出局
4. 类似的模式在其他市场也出现过：1998 年 LTCM（长期资本管理公司）的收敛交易在俄罗斯债务违约后遭遇价差持续扩大，因高杠杆陷入危机，最终由美联储牵头组织多家金融机构注资接管

### 9.5 统计套利的风控工具箱

| 工具 | 做法 | 防范 |
| --- | --- | --- |
| **Z-score 止损** | $\lvert z \rvert > 4$ 强制平仓 | 关系断裂 |
| **时间止损** | 持仓 > 2–3 倍半衰期强制平仓 | 回归速度变慢 |
| **滚动重估** | 定期重做协整检验，不通过的配对移出组合 | 关系漂移 |
| **配对分散** | 同时持有大量、跨行业的配对，单对仓位小 | 个股事件 |
| **事件过滤** | 财报、重组公告、停牌前后不开新仓 | 跳空 |
| **杠杆控制** | 杠杆留有余地，能承受价差先扩大再修复 | 被迫平仓 |
| **拥挤监控** | 跟踪策略收益与公开因子 / 同业指数的相关性；关注换手、价差、融券余额变化 | 踩踏 |
| **压力测试** | 模拟"所有配对价差同时向不利方向扩大 3σ"的情景 | 尾部风险 |

### 10.2 常见陷阱与解决方案

```python
# ❌ 陷阱 1：用相关性选对
corr = returns["A"].corr(returns["B"])     # 0.9 不代表价差会回归
# ✅ 改进：检验协整
_, p, _ = coint(prices["A"], prices["B"])

# ❌ 陷阱 2：对 OLS 残差直接做 ADF，p 值过于乐观
p = adfuller(y - beta * x)[1]
# ✅ 改进：使用协整临界值
p = coint(y, x)[1]

# ❌ 陷阱 3：全样本估计 beta，再在同一样本上回测
beta = sm.OLS(y, sm.add_constant(x)).fit().params.iloc[1]
# ✅ 改进：形成期估计、交易期使用；或滚动 / 卡尔曼
beta_t = kalman_hedge(y.values, x.values)[0][:, 0]

# ❌ 陷阱 4：Z-score 用全样本均值和标准差
z = (spread - spread.mean()) / spread.std()       # 前视偏差
# ✅ 改进：滚动窗口
z = (spread - spread.rolling(L).mean()) / spread.rolling(L).std()

# ❌ 陷阱 5：资金费率套利只算费率收入
pnl = funding.sum() * notional
# ✅ 改进：扣除 4 笔手续费、开平仓基差变化，并评估强平风险
```

| 陷阱 | 后果 | 解决方案 |
| --- | --- | --- |
| 在几千个配对中选出"最好"的 | 选出来的大多是假阳性 | 基本面预筛 + 样本外检验 |
| 忽略做空成本与可行性 | 回测中的空头腿现实中无法执行 | 确认券源 / 用期货替代 |
| 两条腿用不同时间的价格 | 收盘时间不一致造成虚假价差（如跨市场配对）| 严格对齐时间戳 |
| 忽略分红 / 除权 | 价差出现虚假跳空 | 使用复权价格 |
| 期现套利忽略分红季节 | 误判贴水"便宜" | 理论价格中扣除预期分红 |
| 资金费率年化外推 | 用牛市高费率推算全年收益 | 用长周期、包含熊市的费率分布 |
| 高杠杆追求"稳定收益" | 价差先扩大时被迫平仓 | 杠杆以"能扛过历史最坏情况的若干倍"来设定 |

### 11.1 核心概念回顾
