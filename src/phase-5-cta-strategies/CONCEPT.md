## 1. 引言：什么是择时与 CTA

### 1.1 定义

**择时（Market Timing）** 回答的问题是："**现在**该持有多少这个资产？"——是满仓做多、空仓，还是做空。它与 Phase 7 的**选股（横截面选择）** 正好互补：选股回答"买**哪个**"，择时回答"**何时**买、买多少"。

**CTA（Commodity Trading Advisor，商品交易顾问）** 原本是美国监管对期货投资顾问的称呼，后来泛指**在期货市场上做系统化交易**的策略类别。业内说"CTA 策略"，绝大多数时候指的是**多品种期货趋势跟踪**。

用一个比喻：

> 选股像是在一群赛跑选手里押**谁跑得快**；择时 / CTA 像是只盯一条河，判断**水流的方向**——顺流就划船，逆流或者打漩就靠岸。CTA 的精髓是：同时盯几十条河（多品种），每条河只下小注，靠"在大洪水时一定在船上"赚钱。

### 1.2 两大流派：趋势跟踪 vs 均值回归

| 维度 | 趋势跟踪（Trend Following） | 均值回归（Mean Reversion） |
| --- | --- | --- |
| **核心假设** | 价格有惯性，涨了还会涨 | 价格偏离"正常水平"后会回来 |
| **典型指标** | 双均线、MACD、Donchian 通道、海龟 | 布林带、RSI、Z-score |
| **胜率** | 低（常见 30%–40%） | 高（常见 55%–70%） |
| **盈亏比** | 高（小亏多次，大赚几次） | 低（小赚多次，偶尔大亏） |
| **收益分布** | 正偏（右尾长） | 负偏（左尾长） |
| **怕什么** | 来回震荡（whipsaw） | 单边趋势（"接飞刀"） |
| **适合市场** | 商品期货、外汇、国债期货 | 短周期股票、价差、震荡区间 |
| **心理难度** | 长期小亏磨人，回撤期长 | 平时舒服，黑天鹅一次打回原形 |

> 💡 **一个关键事实**：同一个市场在不同周期上可以同时表现出趋势和反转。例如 A 股个股在**月度**上有明显的短期反转效应（Phase 7 会讲），而商品期货在**数周到数月**的周期上趋势性较强。"趋势还是回归"从来不是市场的固有属性，而是**周期 + 品种 + 时代**的组合属性。

## 2. 趋势跟踪策略：均线、MACD 与通道突破

### 2.1 双均线策略（`01-moving-average-crossover.py`）

#### 直觉

移动平均线（Moving Average, MA）就是"过去 N 天的平均价"，它是对价格的**平滑**。短均线反应快、长均线反应慢。当短均线上穿长均线（**金叉**），说明近期价格明显高于更长期的平均水平——趋势可能向上；下穿（**死叉**）则相反。

> 比喻：长均线是"大船的航向"，短均线是"小艇的航向"。小艇已经转向而大船还没转，说明风向可能变了。

#### 公式

简单移动平均（SMA）：

$$
\text{SMA}_t(N) = \frac{1}{N}\sum_{i=0}^{N-1} P_{t-i}
$$

- $P_t$：第 $t$ 天的收盘价
- $N$：窗口长度（天数）

指数移动平均（EMA），对近期价格赋予更高权重：

$$
\text{EMA}_t = \alpha P_t + (1-\alpha)\,\text{EMA}_{t-1}, \quad \alpha = \frac{2}{N+1}
$$

- $\alpha$：平滑系数，越大越"敏感"

交易规则（多空双向版本）：

$$
\text{pos}_{t+1} = \begin{cases} +1, & \text{MA}^{fast}_t > \text{MA}^{slow}_t \\ -1, & \text{MA}^{fast}_t < \text{MA}^{slow}_t \end{cases}
$$

注意下标：**用第 $t$ 天收盘后的信息，决定第 $t+1$ 天的持仓**。这就是 Phase 4 强调的"信号滞后一期"。

#### 代码

```python
import numpy as np
import pandas as pd

def ma_cross_backtest(close: pd.Series, fast: int = 20, slow: int = 60,
                      cost: float = 0.0002) -> pd.DataFrame:
    """双均线多空策略。cost 为单边成本（按名义金额比例）"""
    ma_f = close.rolling(fast).mean()
    ma_s = close.rolling(slow).mean()
    signal = np.sign(ma_f - ma_s)            # +1 / -1，窗口不足时为 NaN
    pos = signal.shift(1).fillna(0)          # 今天收盘出信号，明天才持有
    ret = close.pct_change().fillna(0)
    turnover = pos.diff().abs().fillna(0)    # 从 -1 到 +1 换手为 2
    strat = pos * ret - turnover * cost
    return pd.DataFrame({"pos": pos, "ret": strat, "equity": (1 + strat).cumprod()})
```

#### 量化中的实际意义

- **滞后是本质，不是 bug**。均线必然滞后，趋势策略本来就"不抄底、不逃顶"，只吃中间那段鱼身。想消除滞后（换成更短的均线）只会换来更多假信号。
- **双均线 ≈ 动量**。数学上可以证明，均线差 $\text{MA}^{fast} - \text{MA}^{slow}$ 是过去收益的一个加权和，所以双均线、MACD、时间序列动量（TSMOM）本质上是同一类信号的不同加权方式。不要以为"组合了三个趋势指标"就获得了三份独立信息。

### 2.2 MACD（`03-macd-rsi-strategies.py`）

MACD（Moving Average Convergence Divergence）是"均线差的再平滑"：

$$
\text{DIF}_t = \text{EMA}_t(12) - \text{EMA}_t(26)
$$
$$
\text{DEA}_t = \text{EMA}(\text{DIF}, 9)_t
$$
$$
\text{MACD 柱}_t = 2 \times (\text{DIF}_t - \text{DEA}_t)
$$

- DIF：快慢 EMA 之差，衡量趋势方向与强度
- DEA：DIF 的 9 日 EMA，作为信号线
- 柱状图：国内行情软件惯例乘以 2，海外软件（histogram）通常不乘，**对比数据时注意**

```python
def macd(close: pd.Series, fast=12, slow=26, signal=9) -> pd.DataFrame:
    dif = close.ewm(span=fast, adjust=False).mean() - close.ewm(span=slow, adjust=False).mean()
    dea = dif.ewm(span=signal, adjust=False).mean()
    return pd.DataFrame({"dif": dif, "dea": dea, "hist": 2 * (dif - dea)})

# 常见规则：DIF 上穿 DEA 做多，下穿做空；或者只用 DIF 的符号（等价于 12/26 双均线）
```

> ⚠️ **陷阱**：`ewm(adjust=True)`（pandas 默认）与行情软件的递推算法在序列开头不同，会导致前几十根 K 线的指标对不上。做研究时统一用 `adjust=False`，并丢弃前 `3 × slow` 根左右的"预热期"数据。

### 2.3 通道突破：Donchian 与 Dual Thrust（`04-channel-breakout.py`）

#### Donchian Channel

由 Richard Donchian 提出，是最纯粹的趋势定义："**创 N 日新高就做多，创 N 日新低就做空**"。

$$
\text{Upper}_t = \max(H_{t-N}, \dots, H_{t-1}), \quad \text{Lower}_t = \min(L_{t-N}, \dots, L_{t-1})
$$

- $H, L$：最高价、最低价
- 注意窗口是 **$t-N$ 到 $t-1$，不包含当天**。如果包含当天，"今天的最高价突破了包含今天最高价的通道"永远不成立（或总是成立），这是新手最常见的未来函数之一。

```python
def donchian_signal(df: pd.DataFrame, n_entry=20, n_exit=10) -> pd.Series:
    """突破 n_entry 日高点做多、低点做空；反向突破 n_exit 日极值平仓"""
    up = df["high"].rolling(n_entry).max().shift(1)     # shift(1)：不含当天
    dn = df["low"].rolling(n_entry).min().shift(1)
    exit_long = df["low"].rolling(n_exit).min().shift(1)
    exit_short = df["high"].rolling(n_exit).max().shift(1)

    pos, cur = [], 0
    for c, u, d, el, es in zip(df["close"], up, dn, exit_long, exit_short):
        if cur == 0:
            cur = 1 if c > u else (-1 if c < d else 0)
        elif cur == 1 and c < el:
            cur = 0
        elif cur == -1 and c > es:
            cur = 0
        pos.append(cur)
    return pd.Series(pos, index=df.index).shift(1).fillna(0)   # 次日持有
```

> 这里用循环是因为"持仓状态依赖上一时刻状态"（路径依赖），这种逻辑很难完全向量化。CTA 策略中路径依赖非常普遍（止损、加仓、移动止盈），这也是 Phase 4 事件驱动引擎存在的意义。

#### Dual Thrust

Dual Thrust 是国内期货日内 CTA 中流行的开盘区间突破策略：

$$
\text{Range} = \max(HH - LC,\ HC - LL)
$$

- $HH$：过去 N 日最高价的最大值；$LL$：最低价的最小值
- $HC$：过去 N 日收盘价最大值；$LC$：收盘价最小值

$$
\text{BuyLine} = \text{Open}_t + K_1 \cdot \text{Range}, \quad \text{SellLine} = \text{Open}_t - K_2 \cdot \text{Range}
$$

- $K_1, K_2$：参数，取 $K_1 \ne K_2$ 可以表达多空不对称的偏好

价格盘中上破 BuyLine 做多、下破 SellLine 做空，通常收盘前平仓。它的逻辑是："**今天的波动如果显著超过近期正常波幅，说明有新信息驱动，跟上**"。

> ⚠️ Dual Thrust 是日内策略，用日线数据回测会严重失真：你无法从日线知道"先触发了 BuyLine 还是先触发了 SellLine"。必须用分钟线回测，并考虑**国内期货夜盘**（见 5.8 节）。

### 2.4 趋势策略的收益结构：为什么在震荡市失效

这是本阶段第一个学习检查点。

#### 直觉：止损和假突破

```
价格
  │        ╱╲    ╱╲    ╱╲         震荡市：每次突破都是假突破
  │  ─────╱──╲──╱──╲──╱──╲─────   ← 通道上轨
  │      ╱    ╲╱    ╲╱    ╲        买入 → 回落 → 止损 → 再买入 → ...
  │  ───╱──────────────────╲───   ← 通道下轨
  │                                 每一次都"买在高点、卖在低点"
  └──────────────────────────────▶ 时间

价格
  │                        ╱       趋势市：一次突破吃到整段
  │                    ╱╲╱
  │                ╱╲╱             少数几笔大赚覆盖所有小亏
  │  ─────────╱╲╱─────────────
  │       ╱╲╱
  └──────────────────────────────▶ 时间
```

趋势策略本质上是**"追涨杀跌 + 截断亏损 + 让利润奔跑"**：

1. **追涨**：只有价格已经上涨一段（突破）才买，天然买在相对高位
2. **截断亏损**：反向信号出现就离场，单笔亏损有限
3. **让利润奔跑**：只要趋势不破就一直拿着

在震荡市里，第 1 条让你每次都在区间顶部买入，第 2 条让你在区间底部止损——相当于**系统性地高买低卖**，再加上每次交易的手续费和滑点，持续失血。

#### 更深一层：趋势跟踪像"买期权"

学术上 Fung & Hsieh（2001）指出，趋势跟踪基金的收益结构类似于**回望跨式期权（lookback straddle）**——无论大涨大跌都能赚钱（凸性 / convexity），但市场不动时持续损失"期权费"。

| 市场状态 | 趋势策略 | 类比买入期权 |
| --- | --- | --- |
| 单边大涨 / 大跌 | 大赚 | 期权深度实值 |
| 窄幅震荡 | 小额持续亏损 | 时间价值损耗（Theta） |
| 宽幅震荡、来回打脸 | 最惨，频繁止损 | 买了期权但每次都在错误时点平仓 |

这也解释了为什么 CTA 在股灾、危机期间常有好表现（被称为 **Crisis Alpha**），例如 2008 年全球金融危机中海外 CTA 指数整体录得正收益——危机往往伴随着跨资产的持续单边行情。

> 💡 **实践意义**：接受趋势策略的长期小额回撤是"保险费"。如果你试图用过滤器（ADX、波动率过滤等）把所有震荡期都过滤掉，大概率会在历史数据上过拟合，同时错过下一次大趋势的起点。

## 3. 均值回归策略：布林带与 RSI

### 3.1 布林带均值回归（`02-bollinger-mean-reversion.py`）

#### 直觉

布林带（Bollinger Bands，John Bollinger 提出）在均线上下各画一条"N 倍标准差"的线。如果把价格看成围绕均值随机波动，那么跑出 2 倍标准差之外就是"不太正常"的偏离，**均值回归派**认为它会回来。

> 比喻：均线是一根橡皮筋的固定点，价格被拉得越远，回弹的力越大——前提是橡皮筋**没断**（即"均值"本身没有移动）。

#### 公式

$$
\text{Mid}_t = \text{SMA}_t(N), \quad \text{Upper}_t = \text{Mid}_t + k\,\sigma_t, \quad \text{Lower}_t = \text{Mid}_t - k\,\sigma_t
$$

- $\sigma_t$：过去 $N$ 天收盘价的标准差
- $k$：带宽倍数，经典参数 $N=20, k=2$

把它改写成 Z-score 更通用（Phase 6 配对交易会大量使用）：

$$
z_t = \frac{P_t - \text{Mid}_t}{\sigma_t}
$$

规则：$z_t < -k$ 做多，$z_t > k$ 做空，$z_t$ 回到 0 附近平仓。

```python
def bollinger_mr(close: pd.Series, n=20, k=2.0, exit_z=0.0) -> pd.Series:
    mid = close.rolling(n).mean()
    sd = close.rolling(n).std()
    z = (close - mid) / sd
    pos, cur = [], 0
    for zi in z:
        if np.isnan(zi):
            pos.append(0); continue
        if cur == 0:
            cur = 1 if zi < -k else (-1 if zi > k else 0)
        elif cur == 1 and zi >= -exit_z:
            cur = 0
        elif cur == -1 and zi <= exit_z:
            cur = 0
        pos.append(cur)
    return pd.Series(pos, index=close.index).shift(1).fillna(0)
```

#### 同一根布林带，两种相反的用法

| 用法 | 规则 | 假设 |
| --- | --- | --- |
| **均值回归** | 触及上轨做空、触及下轨做多 | 偏离是噪声，会回来 |
| **突破跟随** | 突破上轨做多、跌破下轨做空 | 偏离是新信息，会延续 |

这再次说明：**指标本身不含观点，规则才含观点**。哪种用法有效，取决于标的在该周期上的统计特性——这需要回测验证，而不是凭感觉。

> ⚠️ **致命陷阱：单边趋势中"接飞刀"**。价格持续下跌时，$z$ 长时间低于 $-2$，均值回归策略会一直持有多头，亏损不断扩大。所以单品种价格层面的均值回归**必须有止损**（例如 $|z| > 4$ 强制离场或时间止损）。Phase 6 将展示：真正适合均值回归的对象是**有经济学理由保证平稳的价差**，而不是单一价格。

### 3.2 RSI（`03-macd-rsi-strategies.py`）

RSI（Relative Strength Index，Welles Wilder 提出）衡量"最近 N 天上涨力量占总力量的比例"：

$$
\text{RS}_t = \frac{\text{AvgGain}_t(N)}{\text{AvgLoss}_t(N)}, \quad \text{RSI}_t = 100 - \frac{100}{1 + \text{RS}_t}
$$

- AvgGain：上涨日涨幅的平滑平均（下跌日记为 0）
- AvgLoss：下跌日跌幅绝对值的平滑平均
- Wilder 原始算法用的平滑是 $\alpha = 1/N$ 的递推平均（也叫 Wilder smoothing / RMA），**不是** $\alpha = 2/(N+1)$ 的 EMA

```python
def rsi(close: pd.Series, n: int = 14) -> pd.Series:
    delta = close.diff()
    gain = delta.clip(lower=0)
    loss = (-delta).clip(lower=0)
    avg_gain = gain.ewm(alpha=1 / n, adjust=False).mean()   # Wilder smoothing
    avg_loss = loss.ewm(alpha=1 / n, adjust=False).mean()
    rs = avg_gain / avg_loss
    return 100 - 100 / (1 + rs)

# 经典规则：RSI < 30 超卖做多，RSI > 70 超买做空
```

**实际意义**：

- RSI 被限制在 0–100，看起来是个"归一化"指标，但它在强趋势中可以长时间停留在 70 以上——"超买"之后还可以更超买。
- 在长周期（日线以上）的商品期货上，RSI 反转规则通常表现不佳；它在**短周期**、**震荡型品种**或作为趋势策略的**入场择机过滤器**（如"趋势向上 + RSI 回落到 40 以下时买入"）时更常见。

### 3.3 趋势与均值回归：用数据判断，不用感觉

判断一个序列在某周期上偏向趋势还是回归，一个简单的工具是**收益自相关**和**方差比（Variance Ratio）**：

$$
\text{VR}(q) = \frac{\text{Var}(r_t + r_{t-1} + \dots + r_{t-q+1})}{q \cdot \text{Var}(r_t)}
$$

- $r_t$：单期收益；$q$：聚合期数
- 若收益独立（随机游走），$\text{VR} \approx 1$
- $\text{VR} > 1$：正自相关，偏趋势
- $\text{VR} < 1$：负自相关，偏回归

```python
def variance_ratio(ret: pd.Series, q: int) -> float:
    r = ret.dropna()
    rq = r.rolling(q).sum().dropna()
    return rq.var() / (q * r.var())

# 对比同一品种 q=5、20、60 下的 VR，可以粗略看到不同周期的特性
```

> 这只是诊断工具，样本内 VR 偏离 1 不代表样本外可交易（还要扣成本、要稳定）。但它能帮你避免"在明显随机游走的序列上硬套策略"。

## 4. 海龟交易法则完整拆解

### 4.1 背景（`05-turtle-trading.py`）

1983 年，期货交易员 Richard Dennis 与 William Eckhardt 打赌"交易能否被教会"，招募了一批学员（"海龟"），传授一套完整的机械化趋势跟踪系统。规则后来由海龟成员 Curtis Faith 在《海龟交易法则》（Way of the Turtle）一书中公开。

海龟系统的价值**不在于入场信号**（就是 Donchian 突破），而在于它是第一个广为人知的**完整交易系统**：信号、仓位、加仓、止损、组合风控一应俱全。

### 4.2 完整规则

| 模块 | 规则 |
| --- | --- |
| **市场** | 流动性好的多品种期货（当年包括国债、外汇、金属、能源、农产品等） |
| **波动度量 N** | 20 日 ATR（Wilder 平滑）：$N_t = \frac{19 N_{t-1} + \text{TR}_t}{20}$ |
| **头寸单位 Unit** | 使 1N 的价格波动 = 账户净值的 1% |
| **入场：系统 1** | 突破 20 日高点 / 低点；若上一次系统 1 的突破信号是盈利交易，则跳过本次（过滤规则） |
| **入场：系统 2** | 突破 55 日高点 / 低点，不做过滤 |
| **加仓** | 每当价格向有利方向移动 0.5N，加 1 个 Unit，单品种最多 4 个 Unit |
| **止损** | 价格反向移动 2N 止损（加仓后所有 Unit 的止损上移到最后加仓价 − 2N） |
| **离场** | 系统 1：反向突破 10 日极值；系统 2：反向突破 20 日极值 |
| **组合限制** | 单品种 ≤ 4 Unit；高度相关品种合计 ≤ 6；松散相关 ≤ 10；单方向总计 ≤ 12 |

### 4.3 ATR 与 Unit：把"波动"翻译成"手数"

**True Range（真实波幅）**：

$$
\text{TR}_t = \max(H_t - L_t,\ |H_t - C_{t-1}|,\ |L_t - C_{t-1}|)
$$

- 比"最高价 − 最低价"多考虑了跳空：如果今天跳空高开，昨日收盘到今日最低价之间的空隙也算作波动

**Unit 计算**：

$$
\text{Unit} = \frac{1\% \times \text{账户净值}}{N \times \text{每点价值}}
$$

- 每点价值（Dollar per Point）= 合约乘数，例如螺纹钢 RB 为 10 吨/手，价格变动 1 元/吨即每手盈亏 10 元

**例子**：账户 100 万元，螺纹钢 $N = 50$ 元/吨，合约乘数 10：

$$
\text{Unit} = \frac{1{,}000{,}000 \times 1\%}{50 \times 10} = 20 \text{ 手}
$$

止损设在 2N，意味着**每个 Unit 的最大预期亏损约为账户的 2%**。加满 4 个 Unit 时风险约 8%（实际取决于加仓价位和跳空）。

```python
def true_range(df: pd.DataFrame) -> pd.Series:
    pc = df["close"].shift(1)
    return pd.concat([df["high"] - df["low"],
                      (df["high"] - pc).abs(),
                      (df["low"] - pc).abs()], axis=1).max(axis=1)

def turtle_n(df: pd.DataFrame, n: int = 20) -> pd.Series:
    return true_range(df).ewm(alpha=1 / n, adjust=False).mean()   # Wilder 平滑

def turtle_unit(equity: float, N: float, multiplier: float, risk_pct=0.01) -> int:
    return int(equity * risk_pct / (N * multiplier))               # 向下取整
```

### 4.4 复现海龟时的工程细节

```
每个交易日收盘后（或盘中逐 bar）：
┌─────────────────────────────────────────────────────────────┐
│ 1. 更新 N（用昨天及之前的 TR）                               │
│ 2. 对每个持仓品种：                                          │
│    ├─ 检查止损（2N）→ 触发则全部平仓                         │
│    ├─ 检查离场（10/20 日反向突破）→ 触发则全部平仓            │
│    └─ 检查加仓（距上次加仓 +0.5N）→ 未满 4 Unit 则加仓       │
│ 3. 对每个空仓品种：                                          │
│    └─ 检查入场（20/55 日突破，含系统 1 的过滤规则）           │
│ 4. 检查组合层 Unit 上限，超限的新信号按优先级丢弃             │
│ 5. 按"每点价值"和手数计算盈亏，扣手续费与滑点                │
└─────────────────────────────────────────────────────────────┘
```

**需要特别小心的地方**：

1. **系统 1 的过滤规则需要"虚拟交易"**：即使跳过了某次突破，也要在后台模拟这笔交易是否盈利，以决定下一次是否跳过。
2. **同一根 K 线内的先后顺序**：日线上同时满足"加仓价"和"止损价"时，你无法知道哪个先发生。保守做法是假设先止损。
3. **Unit 用哪个净值算**：原版规则在账户亏损时按比例缩减名义账户规模（例如亏 10% 则交易规模缩减 20%）。简化复现时至少要用**当前净值**，而不是初始资金。

### 4.5 海龟在今天的启示

海龟原版信号在今天的国内外市场上表现远不如当年，原因包括：趋势跟踪变得拥挤、突破信号被更快的资金提前交易、交易成本结构变化等。但它的**框架**至今仍是 CTA 的标准范式：

- 用**波动率**而不是金额决定仓位（第 6 节）
- 用**多品种**分散单品种的不确定性（第 9 节）
- 用**机械规则**消除情绪
- **止损是系统的一部分**，不是事后补丁

## 5. 期货合约、保证金与展期

### 5.1 期货是什么（`06-futures-contracts-rollover.py`）

> 比喻：期货就像**预售房合同**。你今天和开发商约定"一年后以 300 万买这套房"，交一点定金（保证金）。一年中房价涨了，合同本身就值钱了；跌了，你就亏了。和预售房不同的是，期货合约是**标准化**的，可以在交易所随时转让，而且每天都要按市价结算盈亏。

**期货 vs 股票的核心差异**：

| 维度 | 股票 | 期货 |
| --- | --- | --- |
| 资金占用 | 全额 | 保证金（通常为合约价值的一成左右，因品种和时期而异） |
| 做空 | A 股融券受限 | 双向交易，做空与做多同样方便 |
| 存续期 | 永续 | 有到期日，到期需交割或平仓 |
| 结算 | 买卖时结算 | **逐日盯市**：每天按结算价划转盈亏 |
| 价格连续性 | 一只股票一条价格序列 | 同一品种多个合约同时交易，需拼接 |
| 交易时间 | 日盘 | 许多商品有**夜盘** |

### 5.2 国内期货市场与合约要素

国内期货交易所：

| 交易所 | 代表品种 |
| --- | --- |
| 上海期货交易所（SHFE） | 铜 CU、铝 AL、螺纹钢 RB、热卷 HC、黄金 AU、白银 AG |
| 上海国际能源交易中心（INE） | 原油 SC、20 号胶 NR |
| 大连商品交易所（DCE） | 铁矿石 I、豆粕 M、豆油 Y、焦炭 J、焦煤 JM、聚乙烯 L |
| 郑州商品交易所（CZCE） | 白糖 SR、棉花 CF、PTA TA、甲醇 MA、玻璃 FG |
| 中国金融期货交易所（CFFEX） | 股指期货 IF / IH / IC / IM、国债期货 T / TF / TS / TL |
| 广州期货交易所（GFEX） | 工业硅 SI、碳酸锂 LC |

合约要素（以典型合约为例，**具体数值以交易所最新规则为准**）：

| 要素 | 螺纹钢 RB | 沪深 300 股指期货 IF | 说明 |
| --- | --- | --- | --- |
| 合约乘数 | 10 吨/手 | 每点 300 元 | 价格变动 1 个单位对应的每手盈亏 |
| 最小变动价位 | 1 元/吨 | 0.2 点 | 一个 tick |
| 合约月份 | 1–12 月 | 当月、下月、随后两个季月 | 同时挂牌多个合约 |
| 最后交易日 | 合约月份 15 日（遇节假日顺延） | 合约到期月份第三个周五 | 到期规则各品种不同 |
| 合约代码 | RB2405 = 2024 年 5 月合约 | IF2406 | 郑商所代码只有 3 位数字，如 SR405 |

**合约价值（名义本金）** 是理解杠杆和仓位的基础：

$$
\text{合约价值} = \text{价格} \times \text{合约乘数}
$$

例如 IF 报价 3800 点时，一手合约价值 $3800 \times 300 = 114$ 万元；螺纹钢 3500 元/吨时，一手价值 $3500 \times 10 = 3.5$ 万元。可以看到股指期货单手价值很大——**小资金账户无法精细调整股指期货仓位**，这在组合构建时会形成"仓位颗粒度"问题。

### 5.3 保证金、杠杆与逐日盯市

**保证金**：

$$
\text{占用保证金} = \text{合约价值} \times \text{手数} \times \text{保证金比例}
$$

- 保证金比例 = 交易所最低标准 + 期货公司加收部分
- 交易所会在节假日前、行情剧烈时、合约临近交割时**上调保证金比例**，具体以交易所和期货公司最新通知为准

**杠杆**：若保证金比例为 10%，则名义杠杆约 10 倍——价格反向波动 10%，保证金就全亏光了。

**逐日盯市（Mark-to-Market）**：每个交易日结束后，交易所按当日**结算价**（通常是某个时段的成交量加权平均价，各交易所、各品种算法不同，以交易所规则为准）计算所有持仓的浮动盈亏，直接划入或划出账户。如果账户权益低于维持保证金要求，期货公司会**追加保证金**通知，不补足就会被**强行平仓**。

```
Day 0  开仓：买入 1 手 RB @3500，保证金比例 10%，占用 3,500 元
Day 1  结算价 3450：亏损 (3450-3500)×10 = -500 元，从账户划走
Day 2  结算价 3520：盈利 (3520-3450)×10 = +700 元，划入账户
       注意：盈亏按"结算价"而不是"收盘价"计算
```

> ⚠️ **回测含义**：
> 1. 用收盘价回测和用结算价回测会有小差异，日内策略尤其明显。
> 2. 杠杆是**资金效率**工具，不是风险放大器——风险由**名义敞口**决定。CTA 研究中应当以"名义敞口 / 净值"来衡量风险，而不是保证金占用。通常 CTA 组合的保证金占用控制在净值的 20%–40% 以内，剩余资金作为缓冲。
> 3. 历史上监管曾大幅调整股指期货的保证金、开仓手数限制和平今手续费（例如 2015 年股市异常波动后的限制措施，后来又分阶段放松）。回测跨越这些时期时，**交易成本和容量假设必须随之变化**。

### 5.4 到期、交割与换月

期货合约会到期。到期后要么实物交割（商品期货），要么现金交割（股指期货）。量化 CTA 几乎从不参与交割，所以要在到期前把仓位从旧合约**移到**新合约，这叫**展期 / 换月（Rollover）**。

**为什么不能等到最后一天**：

- 临近到期的合约流动性迅速萎缩，滑点变大
- 交易所会逐步提高临近交割月合约的保证金
- 多数商品期货品种**不允许自然人客户持仓进入交割月**，会被期货公司强平（具体以交易所规则为准）

所以实践中，CTA 交易的是**流动性最好的合约——主力合约**。国内商品期货的主力合约往往集中在少数月份，例如铁矿石的主力通常在 01、05、09 合约间轮换。

### 5.5 主力连续合约的构造

研究 CTA 需要一条长的、连续的价格序列。但每个合约只存在一年左右，所以要把不同时期的主力合约拼接成**主力连续合约**。

**第一步：确定每天的主力合约**

常用规则：以**持仓量**（Open Interest）或成交量最大的合约为主力，并加上约束：

1. **用前一天的数据决定今天的主力**（否则就是未来函数——你在今天开盘时不知道今天收盘后的持仓量）
2. **只向更远月切换，不回切**（避免主力在两个合约间来回跳）
3. 可加"连续 N 天领先才切换"的确认条件

```python
def main_contract(oi: pd.DataFrame) -> pd.Series:
    """oi: index=交易日, columns=合约代码（如 RB2401, RB2405）, values=持仓量
    返回每个交易日应持有的主力合约代码"""
    dominant = oi.idxmax(axis=1).shift(1)          # 今天用昨天收盘后的持仓量决定
    order = {c: i for i, c in enumerate(sorted(oi.columns))}   # 同一品种代码按到期先后可排序
    inv = {i: c for c, i in order.items()}
    rank = dominant.map(order).cummax()            # 只允许向更远月切换
    return rank.map(inv)
```

**第二步：处理换月跳空**

换月那天，旧合约和新合约之间存在价差（例如旧合约 3500，新合约 3550）。如果直接拼接，序列会凭空出现一个 +50 的"跳空"，而你**实际持仓并没有赚这 50 元**——这是一个**虚假收益**，会污染所有指标（均线、ATR、突破信号）和收益计算。

```
直接拼接（错误）：

  旧合约 RB2401: ... 3480  3490  3500 │
  新合约 RB2405:                      │ 3550  3560  3570 ...
                                      ↑
                              虚假跳空 +50，被当成收益
```

### 5.6 价差调整 vs 比例调整

为消除换月跳空，需要对**历史价格**做调整（通常是向后调整 / back-adjust：保持最新价格不变，修改过去的价格）。

| 方法 | 做法 | 优点 | 缺点 |
| --- | --- | --- | --- |
| **价差调整**（Difference / Panama） | 换月日之前的所有价格 **加上** 新旧价差 | 保留**价格点数差**，按点计算的盈亏与真实一致；ATR 等绝对波幅指标不失真 | 历史价格可能变成负数；**百分比收益失真**（同样 50 元的变动在 1000 和 5000 的价位上意义完全不同） |
| **比例调整**（Ratio） | 换月日之前的所有价格 **乘以** 新价 / 旧价 | 保留**百分比收益**，不会出现负价格 | 历史价格的绝对水平和点数差被扭曲，按点计算的止损、ATR 会失真 |
| **不调整** | 直接拼接 | 价格水平真实 | 换月处有虚假跳空 |

数学表达（设换月日为 $d$，换月前一日新旧合约收盘价分别为 $P^{new}_{d-1}$、$P^{old}_{d-1}$）：

$$
\text{价差调整：}\ \tilde{P}_t = P_t + (P^{new}_{d-1} - P^{old}_{d-1}), \quad t < d
$$

$$
\text{比例调整：}\ \tilde{P}_t = P_t \times \frac{P^{new}_{d-1}}{P^{old}_{d-1}}, \quad t < d
$$

多次换月时，调整从最近一次往前**累积**。

```python
def back_adjust(close: pd.DataFrame, main: pd.Series, method: str = "ratio"):
    """close: index=交易日, columns=合约, values=收盘价
    main: 每日主力合约代码（来自 main_contract）
    返回 (未调整拼接价, 调整后连续价)"""
    main = main.dropna()
    raw = pd.Series([close.at[d, c] for d, c in main.items()], index=main.index)
    adj = raw.astype(float).copy()

    prev_main = main.shift(1)
    roll_days = main.index[(main != prev_main) & prev_main.notna()]
    for d in roll_days:
        i = main.index.get_loc(d)
        prev_d = main.index[i - 1]
        p_new = close.at[prev_d, main.loc[d]]       # 换月前一天，新合约价格
        p_old = close.at[prev_d, prev_main.loc[d]]  # 换月前一天，旧合约价格
        before = adj.index < d
        if method == "diff":
            adj[before] += p_new - p_old
        else:
            adj[before] *= p_new / p_old
    return raw, adj
```

> 由于加法和乘法都满足交换律，多次换月的调整顺序不影响结果；这里每次都基于**原始**合约价格计算价差 / 比例，这是正确的。

#### 最佳实践：信号和盈亏分开处理

```
┌──────────────────────────────────────────────────────────────────┐
│                  主力连续数据的正确用法                            │
├──────────────────────────────────────────────────────────────────┤
│                                                                  │
│  计算信号（均线、突破、ATR）                                      │
│    └─▶ 用调整后的连续价格（比例调整更通用）                       │
│                                                                  │
│  计算收益 / 盈亏                                                  │
│    └─▶ 用"当天实际持有合约"的价格变化                             │
│        即 r_t = P_t^{c} / P_{t-1}^{c} - 1，c 为 t-1 日持有的合约   │
│        （比例调整后的连续价格收益率与此等价）                      │
│                                                                  │
│  计算手数 / 保证金 / 合约价值                                     │
│    └─▶ 必须用未调整的真实合约价格                                 │
│                                                                  │
│  计算换月成本                                                     │
│    └─▶ 换月日同时平旧开新，计两次手续费和滑点                     │
│                                                                  │
└──────────────────────────────────────────────────────────────────┘
```

> ⚠️ 很多数据源提供的"主力连续"（如以 `888`、`000` 等后缀命名的序列）**未经复权调整**，直接用来回测会把换月跳空当收益。拿到数据第一件事：检查换月日是否有异常跳空，以及数据源用的是哪种主力切换规则。

### 5.7 期限结构与展期收益

同一品种不同到期月份合约的价格连成一条线，叫**期限结构（Term Structure）**：

```
价格                                   价格
  │            ●───●                     │  ●
  │       ●───●                          │    ●───●
  │  ●───●                               │         ●───●
  │                                      │              ●───●
  └──────────────────▶ 到期月份           └──────────────────▶ 到期月份
   Contango（远期升水）                    Backwardation（远期贴水）
   远月 > 近月                              远月 < 近月
```

- **Contango**：多头展期时"卖便宜的近月、买贵的远月"，若期限结构不变，随着时间推移远月价格会向现货收敛（下跌），**多头持续损失展期收益**
- **Backwardation**：多头展期时"卖贵的近月、买便宜的远月"，**多头获得正的展期收益**

期货的总收益可以近似拆成：

$$
r_{期货} \approx r_{现货价格变化} + r_{展期收益}
$$

**实际意义**：

- 很多时候期货价格"不涨不跌"，但做多的人仍在亏钱（Contango），或在赚钱（Backwardation）。这部分收益**只有用复权后的连续价格才能正确反映**。
- 期限结构本身就是一个有名的 CTA 因子（**Carry 因子**）：做多贴水最深的品种、做空升水最深的品种。
- 国内股指期货中，中证 500（IC）、中证 1000（IM）历史上多数时间处于**贴水**状态，对用股指期货做多替代现货的投资者是正收益来源，对用它做空对冲的指数增强 / 市场中性产品则是成本（Phase 6 期现套利、Phase 7 对冲会再次提到）。

### 5.8 国内期货数据的特有陷阱

| 陷阱 | 说明 | 处理方法 |
| --- | --- | --- |
| **夜盘归属** | 许多商品期货有夜盘（如 21:00 开始）。夜盘交易归属于**下一个交易日**；周五夜盘归属下周一 | 日线以"交易日"为单位聚合，而不是自然日；分钟线要正确标注所属交易日 |
| **夜盘时长不同** | 不同品种夜盘结束时间不同，且历史上有过调整 | 多品种对齐时以交易日对齐，不要按自然时间戳硬对齐 |
| **涨跌停板** | 期货也有涨跌停，封板时无法成交 | 回测时涨停不能买入开仓 / 平空，跌停不能卖出 |
| **平今手续费** | 部分品种当日开仓当日平仓（平今）费率显著更高 | 日内策略必须按平今费率计成本，费率以交易所及期货公司最新标准为准 |
| **合约代码格式** | 郑商所 3 位年月（SR405），其他交易所 4 位（RB2405） | 统一标准化处理，注意郑商所代码的"年份"有十年歧义 |
| **品种上市时间** | 新品种历史短（如工业硅、碳酸锂） | 组合回测时品种池随时间动态变化，避免用"今天存在的品种"回测过去（幸存者偏差） |

## 6. 仓位管理：ATR 与波动率目标

### 6.1 为什么仓位比信号更重要（`07-position-sizing-atr.py`）

假设你对螺纹钢和黄金都用相同的趋势信号，各买 1 手：

| 品种 | 合约价值 | 年化波动 | 1 手的年化风险（金额） |
| --- | --- | --- | --- |
| 螺纹钢 RB | ~3.5 万元 | ~20% | ~0.7 万元 |
| 黄金 AU（1000 克/手） | 数十万元 | ~15% | 数万元 |

"各 1 手"意味着组合的盈亏**几乎完全由黄金决定**，螺纹钢只是噪声。所以 CTA 的仓位原则是：**让每个品种对组合贡献相近的风险**——这就是"风险平价"思想在 CTA 中的应用（Phase 8 会系统讲解）。

> 比喻：组队拔河时不应该按"每人一根绳"分配，而是要按每个人的力气分配位置。波动率就是每个品种的"力气"。

### 6.2 ATR 仓位

ATR（Average True Range）即 TR 的平滑平均，就是海龟中的 $N$。基于 ATR 的仓位公式：

$$
\text{手数} = \frac{\text{净值} \times \text{单笔风险比例}}{k \times \text{ATR} \times \text{合约乘数}}
$$

- 单笔风险比例：例如 0.5%–1%
- $k$：止损距离对应几倍 ATR（海龟用 2）
- 含义：**如果止损被触发，亏损约为净值的固定比例**

### 6.3 波动率目标（Volatility Targeting）

更现代的做法是直接用**收益率波动率**定仓位。目标：让每个品种的年化波动贡献等于设定值。

$$
w_i = \frac{\sigma_{target}}{\hat{\sigma}_i}
$$

- $w_i$：品种 $i$ 的名义敞口占净值的比例（杠杆倍数）
- $\sigma_{target}$：给该品种分配的目标年化波动率，例如 10%
- $\hat{\sigma}_i$：品种 $i$ 的**预测**年化波动率

换算成手数：

$$
\text{手数}_i = \frac{\text{净值} \times w_i}{P_i \times \text{乘数}_i} = \frac{\text{净值} \times \sigma_{target}}{\hat{\sigma}_i \times P_i \times \text{乘数}_i}
$$

**波动率估计**：常用 EWMA（指数加权）估计，对近期数据更敏感：

$$
\hat{\sigma}^2_t = \lambda \hat{\sigma}^2_{t-1} + (1-\lambda) r^2_t, \quad \hat{\sigma}_{annual} = \hat{\sigma}_t \sqrt{252}
$$

- $\lambda$：衰减系数，日频常用 0.94 左右（RiskMetrics 的经典取值），或用 span 为 20–60 天的 EWM

```python
def ewma_vol(ret: pd.Series, span: int = 40) -> pd.Series:
    """年化 EWMA 波动率（用 t 及之前的收益，可用于 t+1 的仓位）"""
    return ret.ewm(span=span, adjust=False).std() * np.sqrt(252)

def vol_target_lots(equity: float, price: float, multiplier: float,
                    ann_vol: float, target_vol: float = 0.10,
                    max_leverage: float = 3.0) -> int:
    weight = min(target_vol / ann_vol, max_leverage)   # 杠杆上限，防止低波动时仓位爆炸
    lots = equity * weight / (price * multiplier)
    return int(lots)                                    # 向零取整

# 例：100 万净值，螺纹钢 3500 元/吨，乘数 10，年化波动 20%，目标 10%
# weight = 0.5 → 目标名义敞口 50 万 → 50 万 / 3.5 万 ≈ 14 手
print(vol_target_lots(1_000_000, 3500, 10, 0.20))   # 14
```

### 6.4 实际意义与陷阱

**为什么波动率目标有效**：

1. **风险均衡**：不同品种的风险贡献可比
2. **波动率聚集**：Phase 3 讲过（GARCH），高波动之后往往还是高波动。波动率上升时自动减仓，相当于自带一层风控
3. **改善 Sharpe**：Moskowitz、Ooi、Pedersen（2012）的时间序列动量（TSMOM）研究中，每个品种都按事前波动率缩放仓位，这是其结果稳健的重要原因之一

**陷阱**：

| 陷阱 | 说明 | 对策 |
| --- | --- | --- |
| **低波动陷阱** | 波动率极低时 $w_i$ 会变得很大，若随后波动突然放大，损失巨大 | 设置杠杆上限 / 波动率下限 |
| **估计滞后** | EWMA 对突发事件反应慢，"黑天鹅第一天"仍是满仓 | 接受这一点；配合止损、组合层风控 |
| **频繁调仓** | 波动率每天变，手数每天变，交易成本上升 | 设置调仓阈值（如目标手数变化 > 10% 才调）|
| **取整误差** | 小资金 + 大合约（如股指期货）时，取整后实际风险与目标差距很大 | 评估最小可行资金量；或改用迷你合约 / ETF |
| **用了未来波动** | 用全样本标准差定仓位 = 前视偏差 | 只用 $t$ 及之前的数据估计 $\hat{\sigma}_t$ |

## 7. 参数优化与参数平原

### 7.1 问题：最优参数往往是最差的选择（`08-parameter-optimization.py`）

对双均线策略遍历 (fast, slow) 组合，选出历史 Sharpe 最高的那一组——这是最自然的想法，也是最危险的做法。回顾 Phase 4：**尝试的次数越多，最优结果中"运气"的成分就越大**。

> 比喻：在山区找一块地盖房子。"孤峰"上视野最好，但风一吹就倒；"高原"上未必最高，但四周都是平地，地基稳。参数选择要找**高原**，不要找**孤峰**。

### 7.2 参数平原 vs 参数孤岛

```
  Sharpe 热力图（行 = 快线周期，列 = 慢线周期）

  孤峰型（危险）                         平原型（稳健）
       20  40  60  80 100                    20  40  60  80 100
   5  0.1 0.2 0.0 0.1 0.2               5   0.5 0.6 0.6 0.5 0.4
  10  0.0 0.3 1.6 0.2 0.1              10   0.6 0.7 0.8 0.7 0.6
  15  0.2 0.1 0.3 0.0 0.2              15   0.6 0.8 0.9 0.8 0.6
  20  0.1 0.2 0.1 0.3 0.1              20   0.5 0.7 0.8 0.7 0.6
           ↑                                         ↑
   最优点 1.6，邻居都很差              最优点 0.9，邻居都不错
   → 大概率是噪声拟合                  → 策略逻辑对参数不敏感，可信度高
```

**参数平原（Parameter Plateau）** 的含义：在最优参数附近的一片区域内，策略表现都比较好、比较平稳。这说明策略的盈利来自**一种结构性规律**，而不是某个精确参数恰好躲过了几次大亏损。

### 7.3 如何选参：平滑后再选

一个实用方法：先对绩效热力图做**邻域平均**，再选平滑后最好的点。这相当于问"哪个参数**及其邻居**平均表现最好"。

```python
import itertools
from scipy.ndimage import uniform_filter

def sharpe(r: pd.Series) -> float:
    return r.mean() / r.std() * np.sqrt(252) if r.std() > 0 else 0.0

def grid_search(close, fasts, slows):
    res = pd.DataFrame(index=fasts, columns=slows, dtype=float)
    for f, s in itertools.product(fasts, slows):
        if f >= s:
            continue
        res.loc[f, s] = sharpe(ma_cross_backtest(close, f, s)["ret"])
    return res

fasts = range(5, 55, 5)
slows = range(20, 260, 20)
grid = grid_search(close, fasts, slows)

# 邻域平均：每个格子替换为 3x3 邻域的均值（无效组合先填为该表最小值，保守处理）
filled = grid.fillna(grid.min().min()).values
smooth = pd.DataFrame(uniform_filter(filled, size=3, mode="nearest"),
                      index=grid.index, columns=grid.columns)

best_raw = grid.stack().idxmax()
best_smooth = smooth.where(grid.notna()).stack().idxmax()
print("单点最优:", best_raw, "平滑后最优:", best_smooth)
```

### 7.4 参数选择原则

| 原则 | 说明 |
| --- | --- |
| **参数少** | 每增加一个参数，过拟合空间指数级增大。海龟核心参数也只有几个 |
| **参数有经济含义** | "20 日 ≈ 一个月"、"250 日 ≈ 一年"，比"37 日"更可信 |
| **取整、取粗网格** | 用 10、20、40、80 这样的几何网格，不要用 1 步长精搜 |
| **看分布不看极值** | 报告所有参数组合的 Sharpe 分布（中位数、正收益占比），而不是只报最优值 |
| **多参数集成** | 不选一个参数，而是**同时运行多组参数并等权平均**（参数分散化），实践中非常常用 |
| **记录尝试次数** | 按课程验收标准，研究日志中记录每次尝试，Phase 9 会用 Deflated Sharpe 校正 |

> 💡 **参数集成**是 CTA 业内的常见做法：例如同时用 20、40、80、160 日四个周期的趋势信号，每个占 1/4 仓位。它牺牲了"单一最优"的漂亮回测，换来对未来市场节奏变化的稳健性。

## 8. 稳健性检验：扰动、分段、跨品种

### 8.1 稳健性检验的目的（`09-robustness-tests.py`）

参数平原只是第一关。稳健性检验要回答：**这个策略的表现，是否依赖于某个特定的参数、时期、品种或成本假设？** 依赖得越少，越可信。

```
┌────────────────────────────────────────────────────────────────┐
│                     稳健性检验四个维度                           │
├────────────────────────────────────────────────────────────────┤
│                                                                │
│   参数维度   ── 参数扰动 ±20%，绩效是否平滑变化？                │
│   时间维度   ── 分段 / 滚动窗口，每段是否都有效？                │
│   截面维度   ── 换品种 / 换板块，逻辑是否通用？                  │
│   成本维度   ── 成本 ×2、滑点 ×2，策略是否还活着？               │
│                                                                │
│   附加：数据维度 ── 换主力规则、换复权方法，结论是否改变？       │
│                                                                │
└────────────────────────────────────────────────────────────────┘
```

### 8.2 参数扰动

对选定参数随机扰动（例如每个参数在 ±20% 范围内均匀抽样），跑几百次，看绩效分布。

```python
rng = np.random.default_rng(42)

def perturb_test(close, base_fast=20, base_slow=100, n=200, pct=0.2):
    sharpes = []
    for _ in range(n):
        f = int(round(base_fast * rng.uniform(1 - pct, 1 + pct)))
        s = int(round(base_slow * rng.uniform(1 - pct, 1 + pct)))
        if f >= s:
            continue
        sharpes.append(sharpe(ma_cross_backtest(close, f, s)["ret"]))
    sharpes = pd.Series(sharpes)
    return sharpes.describe(), (sharpes > 0).mean()
```

**判断**：扰动后 Sharpe 的中位数应接近基准值，且分布不应出现大量负值。如果 ±10% 的扰动就让 Sharpe 从 1.2 掉到 0.2，这个策略不可信。

### 8.3 分段检验

把样本按年份或市场状态切开，分别计算绩效：

```python
def yearly_stats(ret: pd.Series) -> pd.DataFrame:
    g = ret.groupby(ret.index.year)
    return pd.DataFrame({
        "年化收益": g.mean() * 252,
        "年化波动": g.std() * np.sqrt(252),
        "Sharpe": g.mean() / g.std() * np.sqrt(252),
    })
```

**观察要点**：

- 是否有某一两年贡献了绝大部分收益？对趋势策略来说，收益集中在少数大行情年份是**正常的**（例如商品大牛市或大熊市），但你必须意识到这一点，并评估"如果未来几年没有大行情"的情景。
- 近年表现是否明显劣于早年？这可能是**策略衰减**的信号（因子拥挤、市场结构变化）。
- 结合 Phase 4 的 Walk-Forward：**参数只用过去数据选择，在下一段样本外检验**，滚动推进。

### 8.4 跨品种检验

一个有真实逻辑的趋势策略，应当在**多数**品种上有正的期望（不要求每个都赚钱）。

| 检验 | 做法 | 好的迹象 |
| --- | --- | --- |
| **同参数跨品种** | 在螺纹钢上选出的参数，直接用于铁矿、焦炭、铜、豆粕…… | 多数品种 Sharpe > 0 |
| **跨板块** | 黑色、有色、能化、农产品、金融期货分别统计 | 各板块都有效，而非只在一个板块 |
| **跨市场** | 国内期货 vs 海外同类品种 | 逻辑在不同市场都成立 |

> ⚠️ 如果一个参数只在"螺纹钢 2016–2018 年"有效，而在其他品种和时期都无效，这几乎可以确定是过拟合。

### 8.5 成本敏感性

国内商品期货手续费不高，但**滑点**往往被低估。建议至少测试：

- 手续费 ×2
- 滑点从 1 tick 改为 2–3 tick
- 换月时额外加滑点

计算策略的**盈亏平衡成本**：成本提高到多少时 Sharpe 归零？如果平衡成本只比你假设的成本高一点点，说明策略非常脆弱——这在高频率的短周期策略中尤其常见。

### 8.6 稳健性报告清单

| 项目 | 检查内容 | 通过标准（经验参考） |
| --- | --- | --- |
| 参数平原 | 最优点邻域的平均 Sharpe | 不低于最优值的 70% 左右 |
| 参数扰动 | ±20% 扰动下 Sharpe > 0 的比例 | 绝大多数为正 |
| 分年度 | 盈利年份占比；最大单年贡献 | 收益不过度集中于单一年份 |
| 样本外 | Walk-Forward 样本外 Sharpe | 不应显著劣于样本内（有一定衰减是正常的）|
| 跨品种 | 同参数下各品种 Sharpe 分布 | 多数为正 |
| 成本 | 成本 ×2 后的 Sharpe | 仍为正 |
| 数据 | 换主力规则 / 复权方式 | 结论方向不变 |

## 9. 多品种 CTA 组合

### 9.1 为什么要多品种（`10-multi-asset-cta-portfolio.py`）

单品种趋势策略的 Sharpe 往往只有 0.3–0.5，而且可能连续几年不赚钱。但不同品种的趋势是在**不同时间**出现的：今年可能是黑色系大行情，明年可能是农产品，后年可能是国债。分散化让"总有地方有趋势"。

**分散化的数学**：$N$ 个品种，每个波动率 $\sigma$、两两相关系数平均为 $\rho$，等权组合的波动率为：

$$
\sigma_p = \sigma \sqrt{\rho + \frac{1 - \rho}{N}}
$$

若每个品种的 Sharpe 都是 $SR$，则组合 Sharpe 约为：

$$
SR_p \approx SR \times \sqrt{\frac{N}{1 + (N-1)\rho}}
$$

- $\rho = 0$：$SR_p = SR \sqrt{N}$，10 个品种能把 Sharpe 提升约 3.2 倍
- $\rho = 0.3$：$N \to \infty$ 时 $SR_p \to SR / \sqrt{0.3} \approx 1.8\,SR$

```python
def portfolio_sr(sr, n, rho):
    return sr * np.sqrt(n / (1 + (n - 1) * rho))

for rho in [0.0, 0.2, 0.5]:
    print(rho, [round(portfolio_sr(0.4, n, rho), 2) for n in (1, 5, 10, 20, 40)])
# 关键结论：相关性比品种数量更重要。20 个高度相关的品种 ≈ 少数几个独立品种
```

### 9.2 国内期货品种池与板块

| 板块 | 代表品种 | 板块内相关性 |
| --- | --- | --- |
| 黑色 | 螺纹钢、热卷、铁矿石、焦炭、焦煤 | 高 |
| 有色 | 铜、铝、锌、镍 | 中高 |
| 贵金属 | 黄金、白银 | 高 |
| 能化 | 原油、PTA、甲醇、聚乙烯、聚丙烯、沥青 | 中高（多与原油相关）|
| 农产品 | 豆粕、豆油、棕榈油、白糖、棉花、玉米 | 中（油脂内部高）|
| 金融 | 股指期货、国债期货 | 股指之间极高；股债之间通常较低 |

**选品原则**：流动性优先（日均成交额、持仓量）；剔除上市时间过短、流动性差、经常封板的品种；板块尽量均衡。

### 9.3 两层风险预算

```
┌────────────────────────────────────────────────────────────────┐
│                   多品种 CTA 组合构建流程                        │
├────────────────────────────────────────────────────────────────┤
│                                                                │
│  每个品种 i：                                                   │
│    信号 s_i ∈ [-1, 1]  （趋势方向与强度，可多周期集成）          │
│       ×                                                        │
│    品种波动率缩放  σ_target_i / σ̂_i                            │
│       ↓                                                        │
│    品种原始权重 w_i                                             │
│                                                                │
│  组合层：                                                       │
│    板块风险限额（例如单板块风险贡献不超过某个上限）              │
│       ↓                                                        │
│    组合波动率估计 σ̂_p = sqrt(w' Σ w)                           │
│       ↓                                                        │
│    整体缩放 k = σ_portfolio_target / σ̂_p                       │
│       ↓                                                        │
│    最终权重 k × w_i → 换算手数 → 取整 → 检查保证金占用          │
│                                                                │
└────────────────────────────────────────────────────────────────┘
```

```python
def cta_weights(signals: pd.DataFrame, rets: pd.DataFrame,
                target_port_vol=0.15, vol_span=40, cov_window=120,
                max_gross=4.0) -> pd.DataFrame:
    """signals/rets: index=日期, columns=品种。返回各品种名义敞口占净值比例"""
    ann_vol = rets.ewm(span=vol_span, adjust=False).std() * np.sqrt(252)
    raw_w = signals / ann_vol                       # 每个品种风险均衡
    raw_w = raw_w.replace([np.inf, -np.inf], np.nan).fillna(0)

    out = []
    for i, d in enumerate(rets.index):
        if i < cov_window:
            out.append(raw_w.loc[d] * 0); continue
        cov = rets.iloc[i - cov_window + 1:i + 1].cov() * 252   # 只用 d 及之前的数据
        w = raw_w.loc[d].values
        port_vol = np.sqrt(w @ cov.values @ w)
        k = target_port_vol / port_vol if port_vol > 0 else 0
        w_final = w * k
        gross = np.abs(w_final).sum()
        if gross > max_gross:                       # 总杠杆上限
            w_final *= max_gross / gross
        out.append(pd.Series(w_final, index=rets.columns))
    w_df = pd.DataFrame(out, index=rets.index)
    return w_df.shift(1).fillna(0)                  # 次日生效
```

> 这是教学版：每天重算协方差较慢，实际可以每周重算；协方差估计在 Phase 8 会用 Ledoit-Wolf 收缩改进。

**检查点：组合波动率接近设定目标**。回测结束后，计算组合实际实现的年化波动率，与 `target_port_vol` 对比。若偏差较大，常见原因有：

1. 协方差估计窗口太长，跟不上相关性变化（危机时相关性飙升）
2. 杠杆上限或保证金约束频繁触发
3. 手数取整误差（资金量太小）
4. 信号取值不是 ±1 而是连续值，平均敞口低于满仓

### 9.4 时间序列动量（TSMOM）：学术版的 CTA

Moskowitz、Ooi、Pedersen（2012）系统研究了时间序列动量：在数十个流动性好的期货与远期品种（股指、债券、外汇、商品）上，**过去 12 个月收益为正则做多、为负则做空**，并按事前波动率缩放仓位，持有 1 个月。

$$
r^{TSMOM}_{t+1} = \frac{1}{S_t}\sum_{i=1}^{S_t} \text{sign}(r^i_{t-12,t}) \cdot \frac{\sigma_{target}}{\hat{\sigma}^i_t} \cdot r^i_{t,t+1}
$$

- $S_t$：$t$ 时刻可交易品种数
- $\text{sign}(r^i_{t-12,t})$：品种 $i$ 过去 12 个月累计收益的符号
- $\hat{\sigma}^i_t$：品种 $i$ 的事前波动率估计

结论：这种简单策略在几乎所有资产类别上都有显著正收益，且在极端市场中表现较好。它几乎就是"最小可行 CTA"——本阶段实战项目可以先复现 TSMOM 作为基准，再尝试改进。

### 10.2 常见陷阱与解决方案

```python
# ❌ 陷阱 1：通道包含当天，未来函数
upper = df["high"].rolling(20).max()
signal = df["close"] > upper            # 永远不可能为 True（收盘价 ≤ 当日最高价）
# ✅ 改进
upper = df["high"].rolling(20).max().shift(1)

# ❌ 陷阱 2：用未调整的主力连续直接算收益
ret = main_cont_raw.pct_change()        # 换月日出现虚假的大涨大跌
# ✅ 改进：用比例调整后的连续价，或按实际持有合约逐日算收益
ret = adj_close.pct_change()

# ❌ 陷阱 3：用当天收盘价出信号又用当天收盘价成交，且没扣成本
strat = signal * close.pct_change()
# ✅ 改进：信号滞后一期 + 扣换手成本
pos = signal.shift(1)
strat = pos * close.pct_change() - pos.diff().abs() * cost

# ❌ 陷阱 4：用全样本波动率定仓位
w = target_vol / ret.std()              # 用到了未来数据
# ✅ 改进：滚动 / EWMA 估计，只用过去
w = target_vol / (ret.ewm(span=40).std() * np.sqrt(252)).shift(1)

# ❌ 陷阱 5：按"每品种 1 手"构建组合
# ✅ 改进：按波动率目标换算手数，并检查最小资金量和取整误差
```

| 陷阱 | 后果 | 解决方案 |
| --- | --- | --- |
| 在 A 股个股日线上直接套用期货 CTA 参数 | 个股 T+1、涨跌停、做空受限，且短期反转明显 | 期货策略在期货上研究；股票择时以指数 / ETF 为对象 |
| 用主力合约代码表做"上帝视角"切换 | 前视偏差，换月时点完美 | 用 $t-1$ 数据决定 $t$ 日主力 |
| 回测忽略换月成本 | 高估收益，尤其是持有周期长、换月频繁的品种 | 换月日计两笔交易成本 |
| 回测期只覆盖一轮大行情 | 结论严重依赖单一事件 | 至少覆盖多个牛熊周期，分年度报告 |
| 过度添加过滤条件 | 每个过滤器都在历史上"有用"，叠加后严重过拟合 | 每加一个规则都要过稳健性检验 |
| 忽视涨跌停无法成交 | 极端行情中止损无法执行，回测低估尾部损失 | 封板时禁止成交，顺延到下一可交易时点 |
